Làm cách nào để chuyển đổi hình ảnh sang PDF theo lập trình?

Sử dụng [** Aspose.Slides for .NET **](https://products.aspose.com/slides/vi/net/), bất kỳ nhà phát triển hoặc ứng dụng nào cũng có thể chuyển đổi hình ảnh sang định dạng PDF chỉ với một vài dòng mã C#.

Là một API xử lý tài liệu hiện đại, Aspose.Slides for .NET tạo tệp PDF từ hình ảnh JPG hoặc PNG một cách nhanh chóng. Thư viện Aspose PowerPoint cho phép bạn chuyển đổi Hình ảnh sang PDF và nhiều định dạng tệp tin khác

Để cài đặt Aspose.Slides: Mở trình quản lý gói [NuGet](https://www.nuget.org/packages/aspose.slides.net). Tìm kiếm * Aspose.Slides * và cài đặt nó.
 
Hoặc bạn có thể cài đặt ** Aspose.Slides ** bằng cách chạy lệnh này từ Bảng điều khiển Trình quản lý Gói.
