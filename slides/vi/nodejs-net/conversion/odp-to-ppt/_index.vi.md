Để chuyển đổi ODP sang PPT, bạn cần tạo Bản trình bày từ tệp ODP và lưu dưới dạng PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã JavaScript để chuyển đổi ODP thành PPT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.ppt", SaveFormat.Ppt);
}
finally
{
    if (pres != null) pres.dispose();
}
```
