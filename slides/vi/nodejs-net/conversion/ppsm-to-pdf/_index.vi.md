Để chuyển đổi PPSM sang PDF, bạn cần tạo Bản trình bày từ tệp PPSM và lưu dưới dạng PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã JavaScript để chuyển đổi PPSM thành PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsm");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
