Để chuyển đổi POTM sang PPTX, bạn cần tạo Bản trình bày từ tệp POTM và lưu dưới dạng PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã JavaScript để chuyển đổi POTM thành PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
