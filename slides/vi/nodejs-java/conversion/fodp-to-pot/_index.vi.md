Để chuyển đổi FODP sang POT, bạn cần tạo Bản trình bày từ tệp FODP và lưu dưới dạng POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã Node.js để chuyển đổi FODP thành POT" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pot", aspose.slides.SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
