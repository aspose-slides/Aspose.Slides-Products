Để chuyển đổi POTX sang PPTM, bạn cần tạo Bản trình bày từ tệp POTX và lưu dưới dạng PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã Node.js để chuyển đổi POTX thành PPTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
