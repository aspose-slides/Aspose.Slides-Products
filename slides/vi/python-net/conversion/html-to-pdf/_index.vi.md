Để chuyển đổi HTML sang PDF, bạn cần tạo Bản trình bày từ tệp HTML và lưu dưới dạng PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Mã Python để chuyển đổi HTML thành PDF" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("index.pdf", slides.export.SaveFormat.PDF)

```
