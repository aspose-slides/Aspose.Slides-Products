Чтобы преобразовать POTM в FODP, вам нужно будет создать презентацию из файла POTM и сохранить ее как FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования POTM в FODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.fodp", SaveFormat.Fodp);

jpype.shutdownJVM()
```
