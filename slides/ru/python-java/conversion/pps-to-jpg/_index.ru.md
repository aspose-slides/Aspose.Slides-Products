Чтобы преобразовать PPS в JPG, вам нужно будет создать презентацию из файла PPS и сохранить ее как JPG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования PPS в JPG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

for i in range(pres.getSlides().size()):
    buffImage = pres.getSlides().get_Item(i).getThumbnail(2, 2)
    ImageIO.write(buffImage, "JPEG", File("slide" + str(i) + ".jpg"))

jpype.shutdownJVM()
```
