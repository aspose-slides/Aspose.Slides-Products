Чтобы преобразовать ODP в PPTX, вам нужно будет создать презентацию из файла ODP и сохранить ее как PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования ODP в PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.odp");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
