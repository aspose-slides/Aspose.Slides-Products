Чтобы преобразовать POT в PDF, вам нужно будет создать презентацию из файла POT и сохранить ее как PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования POT в PDF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("output.pdf", SaveFormat.Pdf);

jpype.shutdownJVM()
```
