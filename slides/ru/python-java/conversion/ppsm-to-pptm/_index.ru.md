Чтобы преобразовать PPSM в PPTM, вам нужно будет создать презентацию из файла PPSM и сохранить ее как PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования PPSM в PPTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.pptm", SaveFormat.Pptm);

jpype.shutdownJVM()
```
