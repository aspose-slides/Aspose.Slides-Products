Чтобы преобразовать POTX в PDF, вам нужно будет создать презентацию из файла POTX и сохранить ее как PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования POTX в PDF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.pdf", SaveFormat.Pdf);

jpype.shutdownJVM()
```
