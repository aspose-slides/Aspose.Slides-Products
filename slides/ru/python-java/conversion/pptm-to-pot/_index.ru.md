Чтобы преобразовать PPTM в POT, вам нужно будет создать презентацию из файла PPTM и сохранить ее как POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования PPTM в POT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.pot", SaveFormat.Pot);

jpype.shutdownJVM()
```
