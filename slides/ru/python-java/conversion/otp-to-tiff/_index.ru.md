Чтобы преобразовать OTP в TIFF, вам нужно будет создать презентацию из файла OTP и сохранить ее как TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Учебник по Python для преобразования OTP в TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
