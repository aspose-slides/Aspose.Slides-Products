Используя [**Aspose.Slides для .NET**](https://products.aspose.com/slides/ru/net/), вы можете быстро объединять файлы PDF всего несколькими строками кода.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код С# для объединения PDF в PDF" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.RemoveAt(0); // removes default empty slide
    pres.Slides.AddFromPdf("firstFile.pdf");
    pres.Slides.AddFromPdf("secondFile.pdf");

    pres.Save("MergedFile.pdf", SaveFormat.Pdf);
}
```
