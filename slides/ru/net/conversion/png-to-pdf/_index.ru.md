Как программно преобразовать PNG в PDF?

С помощью [**Aspose.Slides for .NET**](https://products.aspose.com/slides/ru/net/) любой разработчик или приложение может конвертировать PNG в формат PDF всего несколькими строками кода C#.

Как современный API обработки документов, Aspose.Slides для .NET быстро создает PDF-файлы из изображений PNG. Библиотека Aspose PowerPoint позволяет конвертировать PNG в PDF и многие другие форматы файлов.

Чтобы установить Aspose.Slides: Откройте менеджер пакетов [NuGet](https://www.nuget.org/packages/aspose.slides.net). Найдите *Aspose.Slides* и установите его.

```cs
using (Presentation pres = new Presentation())
{
    IPPImage image = pres.Images.AddImage(File.ReadAllBytes("image.png"));
    pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);
    pres.Save("image.pdf", SaveFormat.Pdf);
}
```
