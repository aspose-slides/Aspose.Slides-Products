Используя [**Aspose.Slides for .NET**](https://products.aspose.com/slides/ru/net/), вы можете преобразовать изображение JPG в презентацию PowerPoint всего несколькими строками кода:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код C# для преобразования JPG в PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    IPPImage image = pres.Images.AddImage(File.ReadAllBytes("image.jpg"));
    pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);
    pres.Save("Presentation.ppt", SaveFormat.Ppt);
}
```
