Используя [**Aspose.Slides для Python через .NET**](https://products.aspose.com/slides/ru/python-net/), вы можете конвертировать HTML-документ в презентацию PowerPoint всего несколькими строками кода:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код Python для преобразования HTML в PPTX" >}}
```py
import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("page.html", "rb") as htmlStream:
        pres.slides.add_from_html(htmlStream)

    pres.save("MyPresentation.pptx", slides.export.SaveFormat.PPTX)
```
