Чтобы преобразовать PDF в SVG, вам нужно будет создать презентацию из файла PDF и сохранить его как SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код Python для преобразования PDF в SVG" >}}
```python

import aspose.slides as slides
import aspose.pydrawing as drawing
        
with slides.Presentation() as pres:
    pres.slides.add_from_pdf("document.pdf")
    for index in range(pres.slides.length):
        slide = pres.slides[index]

        with open("slide-{index}.svg".format(index = index), "wb") as file:
            slide.write_as_svg(file)

```
