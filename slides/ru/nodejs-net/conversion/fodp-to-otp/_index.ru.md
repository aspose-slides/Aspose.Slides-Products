Чтобы преобразовать FODP в OTP, вам нужно будет создать презентацию из файла FODP и сохранить ее как OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код JavaScript для преобразования FODP в OTP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
