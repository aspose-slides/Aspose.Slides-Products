Чтобы преобразовать PPTX в PPS, вам нужно будет создать презентацию из файла PPTX и сохранить ее как PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код JavaScript для преобразования PPTX в PPS" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.pps", SaveFormat.Pps);
}
finally
{
    if (pres != null) pres.dispose();
}
```
