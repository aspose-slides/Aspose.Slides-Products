Чтобы преобразовать OTP в POT, вам нужно будет создать презентацию из файла OTP и сохранить ее как POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код JavaScript для преобразования OTP в POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
