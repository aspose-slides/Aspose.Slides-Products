Чтобы преобразовать PPTM в GIF, вам нужно будет создать презентацию из файла PPTM и сохранить ее как GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код JavaScript для преобразования PPTM в GIF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.gif", SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
