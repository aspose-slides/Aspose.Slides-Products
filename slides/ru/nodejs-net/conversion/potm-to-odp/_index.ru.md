Чтобы преобразовать POTM в ODP, вам нужно будет создать презентацию из файла POTM и сохранить ее как ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Код JavaScript для преобразования POTM в ODP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.odp", SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
