Используйте Aspose.Slides for C++, чтобы разбирать файлы презентаций PPTX и извлекать текст со слайдов. API предоставляет текст слайдов через `SlideUtil::GetAllTextBoxes`, `ITextFrame`, `IParagraph` и `IPortion`, поэтому текст можно читать без автоматизации Microsoft PowerPoint. Установите пакет [`Aspose.Slides.Cpp`](https://www.nuget.org/packages/Aspose.Slides.Cpp/) из NuGet или выполните команду ниже в консоли диспетчера пакетов.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Разбор файлов PPTX — C++" >}}
```cpp
auto presentation = MakeObject<Presentation>(u"presentation.pptx");
auto textFrames = SlideUtil::GetAllTextBoxes(presentation->get_Slide(0));

for (auto&& textFrame : textFrames)
{
    for (auto&& paragraph : textFrame->get_Paragraphs())
    {
        for (auto&& portion : paragraph->get_Portions())
        {
            Console::WriteLine(portion->get_Text());
        }
    }
}

presentation->Dispose();
```
