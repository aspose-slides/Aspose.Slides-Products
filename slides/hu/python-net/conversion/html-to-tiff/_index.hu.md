A HTML formátum TIFF formátumra konvertálásához létre kell hoznia egy prezentációt a HTML fájlból, és el kell mentenie TIFF néven.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python kód a HTML TIFF formátumba való konvertálásához" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("doc.tiff", slides.export.SaveFormat.TIFF)

```
