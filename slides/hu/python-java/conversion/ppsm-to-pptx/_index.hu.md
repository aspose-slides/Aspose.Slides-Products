A PPSM formátum PPTX formátumra konvertálásához létre kell hoznia egy prezentációt a PPSM fájlból, és el kell mentenie PPTX néven.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python oktatóanyag a PPSM PPTX formátumba való konvertálásához" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
