A POTX formátum POTM formátumra konvertálásához létre kell hoznia egy prezentációt a POTX fájlból, és el kell mentenie POTM néven.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python oktatóanyag a POTX POTM formátumba való konvertálásához" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
