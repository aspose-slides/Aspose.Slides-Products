A PPS formátum GIF formátumra konvertálásához létre kell hoznia egy prezentációt a PPS fájlból, és el kell mentenie GIF néven.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python oktatóanyag a PPS GIF formátumba való konvertálásához" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.gif", SaveFormat.Gif);

jpype.shutdownJVM()
```
