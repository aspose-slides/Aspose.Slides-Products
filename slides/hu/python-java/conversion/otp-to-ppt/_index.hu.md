A OTP formátum PPT formátumra konvertálásához létre kell hoznia egy prezentációt a OTP fájlból, és el kell mentenie PPT néven.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python oktatóanyag a OTP PPT formátumba való konvertálásához" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.ppt", SaveFormat.Ppt);

jpype.shutdownJVM()
```
