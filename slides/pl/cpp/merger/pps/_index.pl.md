```cs
// The path to the documents directory.
const String sourceFilePath1 = u"SourceFile2.pps";
const String sourceFilePath2 = u"SourceFile3.pps";
const String outputFilePath = u"mergedOutput.pps";

// Instantiate Presentation class
SharedPtr<Presentation> presentation1 = MakeObject<Presentation>(sourceFilePath1);
SharedPtr<Presentation> presentation2 = MakeObject<Presentation>(sourceFilePath2);

for (SharedPtr<ISlide> slide : presentation2->get_Slides()){
	// Merge from source to destination 
	presentation1->get_Slides()->AddClone(slide);
}

// Save the presentation
presentation1->Save(outputFilePath, SaveFormat::Pps);  

```

{{% blocks/products/pf/slides-design-update-10-2026/about-format format="PPS" readMoreLink="https://docs.fileformat.com/presentation/pps/" %}}

PPS (pokaz slajdów PowerPoint) to binarny format pokazów slajdów używany przez PowerPoint 97–2003. PPSX to nowszy format pokazów slajdów oparty na standardzie Office Open XML. Obecne wersje PowerPoint mogą otwierać pliki PPS i nadal zapisywać prezentacje w formacie PPS. Po zwykłym otwarciu plik PPS uruchamia się w trybie pokazu slajdów, a plik PPT otwiera się w trybie edycji.
