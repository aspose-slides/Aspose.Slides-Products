Używając [**Aspose.Slides for .NET**](https://products.aspose.com/slides/pl/net/), możesz przekonwertować obraz JPG na prezentację PowerPoint za pomocą zaledwie kilku linijek kodu:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod C# do konwersji JPG na PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    IPPImage image = pres.Images.AddImage(File.ReadAllBytes("image.jpg"));
    pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);
    pres.Save("Presentation.ppt", SaveFormat.Ppt);
}
```
