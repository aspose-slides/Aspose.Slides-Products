Jak programowo przekonwertować obraz do formatu PDF?

Używając [**Aspose.Slides for .NET**](https://products.aspose.com/slides/pl/net/), każdy programista lub aplikacja może przekonwertować obraz na format PDF za pomocą zaledwie kilku wierszy kodu C#.

Jako nowoczesny interfejs API do przetwarzania dokumentów, Aspose.Slides for .NET szybko tworzy pliki PDF z obrazów JPG lub PNG. Biblioteka Aspose PowerPoint umożliwia konwersję obrazu do formatu PDF i wielu innych formatów plików

Aby zainstalować Aspose.Slides: Otwórz menedżera pakietów [NuGet](https://www.nuget.org/packages/aspose.slides.net). Wyszukaj *Aspose.Slides* i zainstaluj go.

```cs
using (Presentation pres = new Presentation())
{
    IPPImage image = pres.Images.AddImage(File.ReadAllBytes(imagePath));
    pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);
    pres.Save("image.pdf", SaveFormat.Pdf);
}
```
