Aby przekonwertować plik PPS na OTP, musisz utworzyć prezentację z pliku PPS i zapisać ją jako OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Samouczek Pythona dotyczący konwersji PPS na OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
