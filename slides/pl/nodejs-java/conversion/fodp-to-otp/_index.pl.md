Aby przekonwertować plik FODP na OTP, musisz utworzyć prezentację z pliku FODP i zapisać ją jako OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod Node.js do konwersji FODP na OTP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.otp", aspose.slides.SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
