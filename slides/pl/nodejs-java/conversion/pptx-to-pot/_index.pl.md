Aby przekonwertować plik PPTX na POT, musisz utworzyć prezentację z pliku PPTX i zapisać ją jako POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod Node.js do konwersji PPTX na POT" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.pot", aspose.slides.SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
