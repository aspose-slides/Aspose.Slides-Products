Aby przekonwertować plik PPT na PPSM, musisz utworzyć prezentację z pliku PPT i zapisać ją jako PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji PPT na PPSM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.ppsm", SaveFormat.Ppsm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
