Aby przekonwertować plik PPS na HTML, musisz utworzyć prezentację z pliku PPS i zapisać ją jako HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji PPS na HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
