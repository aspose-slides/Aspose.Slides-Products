Aby przekonwertować plik POTX na OTP, musisz utworzyć prezentację z pliku POTX i zapisać ją jako OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji POTX na OTP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
