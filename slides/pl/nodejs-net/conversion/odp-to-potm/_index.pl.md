Aby przekonwertować plik ODP na POTM, musisz utworzyć prezentację z pliku ODP i zapisać ją jako POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji ODP na POTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.potm", SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
