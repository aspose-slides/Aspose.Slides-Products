Aby przekonwertować plik POTX na FODP, musisz utworzyć prezentację z pliku POTX i zapisać ją jako FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji POTX na FODP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.fodp", SaveFormat.Fodp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
