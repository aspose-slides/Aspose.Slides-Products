Aby przekonwertować plik PPSX na PPTX, musisz utworzyć prezentację z pliku PPSX i zapisać ją jako PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod JavaScript do konwersji PPSX na PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
