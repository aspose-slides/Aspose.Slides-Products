Aby przekonwertować HTML na PDF, musisz utworzyć Prezentację z pliku HTML i zapisać ją jako PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kod Java do konwersji HTML na PDF" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().removeAt(0);
    FileInputStream tr = new FileInputStream("file.html");
    pres.getSlides().addFromHtml(tr);
    pres.save("index.pdf", SaveFormat.Pdf);
} finally {
    if (pres != null) pres.dispose();
}
```
