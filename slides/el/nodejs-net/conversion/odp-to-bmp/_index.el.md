Για να μετατρέψετε το ODP σε BMP, θα χρειαστεί να δημιουργήσετε την Παρουσίαση από το αρχείο ODP και να την αποθηκεύσετε ως BMP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Κώδικας JavaScript για μετατροπή ODP σε BMP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    for (let i = 0; i < pres.slides.length; i++) {
        var slide = pres.slides.get(i);
        var image = slide.getThumbnail(new asposeSlides.RenderingOptions(), { width: 1080, height: 960 });

        image.save("slide" + i + ".bmp", ImageFormat.Bmp); 
    }
}
finally
{
    if (pres != null) pres.dispose();
}
```
