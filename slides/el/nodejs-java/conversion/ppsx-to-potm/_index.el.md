Για να μετατρέψετε το PPSX σε POTM, θα χρειαστεί να δημιουργήσετε την Παρουσίαση από το αρχείο PPSX και να την αποθηκεύσετε ως POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Κώδικας Node.js για μετατροπή PPSX σε POTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.potm", aspose.slides.SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
