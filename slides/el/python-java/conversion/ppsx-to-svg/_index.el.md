Για να μετατρέψετε το PPSX σε SVG, θα χρειαστεί να δημιουργήσετε την Παρουσίαση από το αρχείο PPSX και να την αποθηκεύσετε ως SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Οδηγός Python για τη μετατροπή του PPSX σε SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
