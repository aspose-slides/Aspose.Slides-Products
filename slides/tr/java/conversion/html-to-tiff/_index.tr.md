HTML dosyasını TIFF biçimine dönüştürmek için, HTML dosyasından Sunu oluşturmanız ve onu TIFF olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="HTML biçimini TIFF biçimine dönüştürmek için Java kodu" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().removeAt(0);
    FileInputStream tr = new FileInputStream("file.html");
    pres.getSlides().addFromHtml(tr);
    pres.save("doc.tiff", SaveFormat.Tiff);
} finally {
    if (pres != null) pres.dispose();
}
```
