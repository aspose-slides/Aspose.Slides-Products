POTM dosyasını PPSX biçimine dönüştürmek için, POTM dosyasından Sunum oluşturmanız ve bunu PPSX olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="POTM biçimini PPSX biçimine dönüştürmek için Node.js kodu" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.ppsx", aspose.slides.SaveFormat.Ppsx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
