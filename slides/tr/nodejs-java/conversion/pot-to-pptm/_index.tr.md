POT dosyasını PPTM biçimine dönüştürmek için, POT dosyasından Sunum oluşturmanız ve bunu PPTM olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="POT biçimini PPTM biçimine dönüştürmek için Node.js kodu" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
