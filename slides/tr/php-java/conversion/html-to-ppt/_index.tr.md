HTML dosyasını PPT biçimine dönüştürmek için, HTML dosyasından Sunu oluşturmanız ve onu PPT olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="HTML biçimini PPT biçimine dönüştürmek için PHP kodu" >}}
```php

<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once("lib/aspose.slides.php");
        
$pres = new Presentation();
try
{
    $pres->getSlides()->removeAt(0);
    
    $filename = 'file.html';
    $f = fopen($filename, 'r');
    if ($f) {
        $contents = fread($f, filesize($filename));
        fclose($f);
    }
    
    $pres->getSlides()->addFromHtml($contents);        
    $pres->save("output.ppt", SaveFormat::Ppt);        
}
finally
{
    if ($pres != null) $pres->dispose();
}
?>
```
