HTML dosyasını PDF biçimine dönüştürmek için, HTML dosyasından Sunu oluşturmanız ve onu PDF olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="HTML biçimini PDF biçimine dönüştürmek için Python kodu" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("index.pdf", slides.export.SaveFormat.PDF)

```
