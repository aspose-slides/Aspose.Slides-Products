PPS dosyasını FODP biçimine dönüştürmek için, PPS dosyasından Sunum oluşturmanız ve bunu FODP olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPS biçimini FODP biçimine dönüştürmek için JavaScript kodu" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("output.fodp", SaveFormat.Fodp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
