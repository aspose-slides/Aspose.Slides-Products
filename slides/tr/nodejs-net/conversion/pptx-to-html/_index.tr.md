PPTX dosyasını HTML biçimine dönüştürmek için, PPTX dosyasından Sunum oluşturmanız ve bunu HTML olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPTX biçimini HTML biçimine dönüştürmek için JavaScript kodu" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
