PPTX dosyasını OTP biçimine dönüştürmek için, PPTX dosyasından Sunum oluşturmanız ve bunu OTP olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPTX biçimini OTP biçimine dönüştürmek için JavaScript kodu" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
