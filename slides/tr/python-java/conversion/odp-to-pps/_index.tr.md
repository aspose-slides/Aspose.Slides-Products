ODP dosyasını PPS biçimine dönüştürmek için, ODP dosyasından Sunum oluşturmanız ve bunu PPS olarak kaydetmeniz gerekir.

{{< blocks/products/pf/slides-design-update-10-2026/code title="ODP'ı PPS'a dönüştürmek için Python eğitimi" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.odp");

pres.save("output.pps", SaveFormat.Pps);

jpype.shutdownJVM()
```
