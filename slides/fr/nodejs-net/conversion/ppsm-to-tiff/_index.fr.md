Pour convertir le PPSM en TIFF, vous devrez créer une présentation à partir du fichier PPSM et l'enregistrer sous TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code JavaScript pour convertir PPSM en TIFF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsm");
try
{
    pres.save("output.tiff", SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
