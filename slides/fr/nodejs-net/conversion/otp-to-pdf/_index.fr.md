Pour convertir le OTP en PDF, vous devrez créer une présentation à partir du fichier OTP et l'enregistrer sous PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code JavaScript pour convertir OTP en PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
