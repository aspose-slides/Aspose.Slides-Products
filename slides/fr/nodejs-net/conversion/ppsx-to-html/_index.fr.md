Pour convertir le PPSX en HTML, vous devrez créer une présentation à partir du fichier PPSX et l'enregistrer sous HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code JavaScript pour convertir PPSX en HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
