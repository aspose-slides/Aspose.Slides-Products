Pour convertir le POTX en GIF, vous devrez créer une présentation à partir du fichier POTX et l'enregistrer sous GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code JavaScript pour convertir POTX en GIF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.gif", SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
