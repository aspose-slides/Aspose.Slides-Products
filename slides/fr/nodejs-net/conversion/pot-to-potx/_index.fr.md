Pour convertir le POT en POTX, vous devrez créer une présentation à partir du fichier POT et l'enregistrer sous POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code JavaScript pour convertir POT en POTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.potx", SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
