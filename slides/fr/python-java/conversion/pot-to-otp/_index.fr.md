Pour convertir le POT en OTP, vous devrez créer une présentation à partir du fichier POT et l'enregistrer sous OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutoriel Python pour convertir POT en OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
