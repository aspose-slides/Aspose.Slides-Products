Pour convertir le PPSX en SVG, vous devrez créer une présentation à partir du fichier PPSX et l'enregistrer sous SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutoriel Python pour convertir PPSX en SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
