Pour convertir le PPS en POT, vous devrez créer une présentation à partir du fichier PPS et l'enregistrer sous POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutoriel Python pour convertir PPS en POT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.pot", SaveFormat.Pot);

jpype.shutdownJVM()
```
