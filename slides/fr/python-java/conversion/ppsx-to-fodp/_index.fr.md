Pour convertir le PPSX en FODP, vous devrez créer une présentation à partir du fichier PPSX et l'enregistrer sous FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutoriel Python pour convertir PPSX en FODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

pres.save("output.fodp", SaveFormat.Fodp);

jpype.shutdownJVM()
```
