Pour convertir le OTP en TIFF, vous devrez créer une présentation à partir du fichier OTP et l'enregistrer sous TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutoriel Python pour convertir OTP en TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
