Pour convertir le FODP en PPS, vous devrez créer une présentation à partir du fichier FODP et l'enregistrer sous PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Node.js pour convertir FODP en PPS" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pps", aspose.slides.SaveFormat.Pps);
}
finally
{
    if (pres != null) pres.dispose();
}
```
