Pour convertir le PPSX en GIF, vous devrez créer une présentation à partir du fichier PPSX et l'enregistrer sous GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Node.js pour convertir PPSX en GIF" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.gif", aspose.slides.SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
