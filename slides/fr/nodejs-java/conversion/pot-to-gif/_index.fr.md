Pour convertir le POT en GIF, vous devrez créer une présentation à partir du fichier POT et l'enregistrer sous GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Node.js pour convertir POT en GIF" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.gif", aspose.slides.SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
