Pour convertir le PDF en TIFF, vous devrez créer une présentation à partir du fichier PDF et l'enregistrer sous le nom TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Java pour convertir PDF en TIFF" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    pres.save("doc.tiff", SaveFormat.Tiff);
} finally {
    if (pres != null) pres.dispose();
}
```
