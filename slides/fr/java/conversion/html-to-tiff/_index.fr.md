Pour convertir le HTML en TIFF, vous devrez créer une présentation à partir du fichier HTML et l'enregistrer sous le nom TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Java pour convertir HTML en TIFF" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().removeAt(0);
    FileInputStream tr = new FileInputStream("file.html");
    pres.getSlides().addFromHtml(tr);
    pres.save("doc.tiff", SaveFormat.Tiff);
} finally {
    if (pres != null) pres.dispose();
}
```
