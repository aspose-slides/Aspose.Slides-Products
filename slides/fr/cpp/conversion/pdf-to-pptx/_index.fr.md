{{< blocks/products/pf/slides-design-update-10-2026/code title="Code C++ pour convertir PDF en PPTX" >}}
```cpp

pres->get_Slides()->AddFromPdf(u"InputPDF.pdf");
pres->Save(u"pres.pptx", SaveFormat::Pptx);

```
