Pour convertir le HTML en XML, vous devrez créer une présentation à partir du fichier HTML et l'enregistrer sous le nom XML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code PHP pour convertir HTML en XML" >}}
```php

<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once("lib/aspose.slides.php");
        
$pres = new Presentation();
try
{
    $pres->getSlides()->removeAt(0);
    
    $filename = 'file.html';
    $f = fopen($filename, 'r');
    if ($f) {
        $contents = fread($f, filesize($filename));
        fclose($f);
    }
    
    $pres->getSlides()->addFromHtml($contents);        
    for ($i = 0; $i < java_values($pres->getSlides()->size()); $i++)
    {
        $slide = $pres->getSlides()->get_Item($i);
        $javafos = new Java("java.io.FileOutputStream", "slide_". $i .".xml");
        $slide->writeAsSvg($javafos);
    }        
}
finally
{
    if ($pres != null) $pres->dispose();
}
?>
```
