Pour convertir le HTML en XML, vous devrez créer une présentation à partir du fichier HTML et l'enregistrer sous le nom XML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Python pour convertir HTML en XML" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    for index, slide in enumerate(pres.slides):

        with open("slide-{index}.xml".format(index = index), "wb") as file:
            slide.write_as_svg(file)

```
