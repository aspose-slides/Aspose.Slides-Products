En utilisant [**Aspose.Slides pour Python via .NET**](https://products.aspose.com/slides/fr/python-net/), vous pouvez convertir un document HTML en présentation PowerPoint avec seulement quelques lignes de code :

{{< blocks/products/pf/slides-design-update-10-2026/code title="Code Python pour convertir HTML en PPT" >}}
```py
import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("page.html", "rb") as htmlStream:
        pres.slides.add_from_html(htmlStream)

    pres.save("MyPresentation.ppt", slides.export.SaveFormat.PPT)
```
