var ps1 = new Presentation("presen1.pptm");
    var ps2 = new Presentation("presen2.pptx");
    
    //merged Presentation 
    var mp = new Presentation("template.pptx");
    while (mp.Slides.Count > 0){
        mp.Slides.RemoveAt(0);
    }
    // master slide
    var ms = mp.Masters[0];
    
    // The first PPTM presentation is added with its own styles.
    foreach (var slide in ps1.Slides){
        mp.Slides.AddClone(slide);
    }
    
    // The second PPTX presentation is added with template presentation styles using.
    foreach (var slide in ps2.Slides){
        mp.Slides.AddClone(slide, ms, true);
    }
    
    // It is possible to save the merged presentation to any supported format.
    mp.Save("mp.pptx", SaveFormat.Pptx);
    mp.Save("mp.pptx", SaveFormat.Pdf);

{{% blocks/products/pf/slides-design-update-10-2026/about-format format="PPTM" readMoreLink="https://docs.fileformat.com/presentation/pptm/" %}}

Les fichiers portant l’extension `.PPTM` sont des fichiers de présentation prenant en charge les macros, introduits avec Microsoft PowerPoint 2007. Ils ressemblent aux fichiers PPTX, mais les fichiers PPTM peuvent stocker du code de macro VBA, ce que les fichiers PPTX ne peuvent pas faire. Les fichiers PPTM peuvent être ouverts et modifiés dans Microsoft PowerPoint. Le format apparenté PPSM s’ouvre par défaut en mode diaporama, mais peut aussi être ouvert dans PowerPoint pour être modifié. Comme les fichiers PPTX, les fichiers PPTM peuvent contenir du texte, des images, des vidéos, des graphiques et d’autres contenus de présentation.
