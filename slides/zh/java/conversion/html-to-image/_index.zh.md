要将 HTML 转换为 Image，您需要从 HTML 文件创建演示文稿并将其另存为 Image。

{{< blocks/products/pf/slides-design-update-10-2026/code title="将 HTML 转换为 Image 的 Java 代码" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().removeAt(0);
    FileInputStream tr = new FileInputStream("file.html");
    pres.getSlides().addFromHtml(tr);
    Dimension size = new Dimension(960, 720);
    for (int index = 0; index < pres.getSlides().size(); index++)
    {
        ISlide slide = pres.getSlides().get_Item(index);
        IImage image = slide.getImage(size);
        image.save("image_java_" + index + ".png", ImageFormat.Png);
    }
} finally {
    if (pres != null) pres.dispose();
}
```
