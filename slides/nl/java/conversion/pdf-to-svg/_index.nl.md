Om de PDF naar SVG te converteren, moet u een presentatie maken van het PDF-bestand en deze opslaan als SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Java-code voor het converteren van PDF naar SVG" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    for (int index = 0; index < pres.getSlides().size(); index++)
    {
        ISlide slide = pres.getSlides().get_Item(index);

        FileOutputStream fileStream = new FileOutputStream("slide-" + index + ".svg");
        try {
            slide.writeAsSvg(fileStream);
        } finally {
            fileStream.close();
        }
    }
} finally {
    if (pres != null) pres.dispose();
}
```
