Om de PDF naar PPTX te converteren, moet u een presentatie maken van het PDF-bestand en deze opslaan als PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Java-code voor het converteren van PDF naar PPTX" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    pres.save("OutputPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
