Om de afbeelding naar PPTX te converteren, moet u een presentatie maken van een afbeeldingsbestand en deze opslaan als PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-code voor het converteren van afbeelding naar PPTX" >}}
```python

import aspose.slides as slides
import aspose.pydrawing as drawing

with slides.Presentation() as pres:
    slide = pres.slides[0]
    image = pres.images.add_image(drawing.Bitmap(dataDir+ "image.png"))
	slide.shapes.add_picture_frame(slides.ShapeType.RECTANGLE, 0, 0, 720, 540, image)
    pres.save("index.pptx", slides.export.SaveFormat.PPTX)

```
