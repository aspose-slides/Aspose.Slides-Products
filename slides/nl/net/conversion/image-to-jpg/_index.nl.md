Hoe converteer ik een afbeelding naar JPG in code?

Als een moderne API voor documentverwerking, exporteert Aspose.Slides voor .NET afbeeldingen in populaire formaten snel naar JPG. Met de Aspose PowerPoint-bibliotheek kunt u afbeeldingen converteren naar JPG en vele andere afbeeldingsindelingen.

Om Aspose.Slides te installeren: Open [NuGet](https://www.nuget.org/packages/aspose.slides.net) pakketbeheerder. Zoek naar *Aspose.Slides* en installeer het.
 
Of u kunt **Aspose.Slides** installeren door deze opdracht uit te voeren vanuit de Package Manager Console.

using (Presentation pres = new Presentation())

        IPPImage image = pres.Images.AddImage(File.ReadAllBytes(imagePath));
        pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);

        pres.Slides[0].GetThumbnail(new Size(960, 720)).Save($"image.jpg", ImageFormat.Jpeg);
    }
