Met behulp van [**Aspose.Slides for .NET**](https://products.aspose.com/slides/nl/net/) kunt u met slechts een paar regels code een PDF converteren naar een PowerPoint-presentatie:

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-code voor het converteren van PDF naar PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromPdf("InputPDF.pdf");
    pres.Save("OutputPresentation.ppt", SaveFormat.Ppt);
}
```
