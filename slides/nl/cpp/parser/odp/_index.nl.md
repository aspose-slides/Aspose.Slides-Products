Gebruik Aspose.Slides for C++ om ODP-presentatiebestanden te parseren en tekst uit dia's te extraheren. De API biedt de diatekst via `SlideUtil::GetAllTextBoxes`, `ITextFrame`, `IParagraph` en `IPortion`, zodat u tekst kunt lezen zonder Microsoft PowerPoint te automatiseren. Installeer het pakket [`Aspose.Slides.Cpp`](https://www.nuget.org/packages/Aspose.Slides.Cpp/) via NuGet of gebruik de onderstaande opdracht in de Package Manager Console.

{{< blocks/products/pf/slides-design-update-10-2026/code title="ODP-bestanden parseren – C++" >}}
```cpp
auto presentation = MakeObject<Presentation>(u"presentation.odp");
auto textFrames = SlideUtil::GetAllTextBoxes(presentation->get_Slide(0));

for (auto&& textFrame : textFrames)
{
    for (auto&& paragraph : textFrame->get_Paragraphs())
    {
        for (auto&& portion : paragraph->get_Portions())
        {
            Console::WriteLine(portion->get_Text());
        }
    }
}

presentation->Dispose();
```
