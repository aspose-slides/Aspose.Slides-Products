Om het bestand PPSM naar HTML te converteren, moet u een presentatie maken van het bestand PPSM en dit opslaan als HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van PPSM naar HTML" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
