Om het bestand PPTX naar POTX te converteren, moet u een presentatie maken van het bestand PPTX en dit opslaan als POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van PPTX naar POTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptx");

pres.save("output.potx", SaveFormat.Potx);

jpype.shutdownJVM()
```
