Om het bestand FODP naar PPTX te converteren, moet u een presentatie maken van het bestand FODP en dit opslaan als PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van FODP naar PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.fodp");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
