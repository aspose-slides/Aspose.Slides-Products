Om het bestand POTX naar SVG te converteren, moet u een presentatie maken van het bestand POTX en dit opslaan als SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van POTX naar SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
