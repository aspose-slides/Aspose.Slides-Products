Om het bestand POTM naar PPT te converteren, moet u een presentatie maken van het bestand POTM en dit opslaan als PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van POTM naar PPT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.ppt", SaveFormat.Ppt);

jpype.shutdownJVM()
```
