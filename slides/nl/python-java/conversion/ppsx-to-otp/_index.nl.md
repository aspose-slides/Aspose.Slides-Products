Om het bestand PPSX naar OTP te converteren, moet u een presentatie maken van het bestand PPSX en dit opslaan als OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van PPSX naar OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
