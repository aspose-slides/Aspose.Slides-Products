Om het bestand PPTM naar PPS te converteren, moet u een presentatie maken van het bestand PPTM en dit opslaan als PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van PPTM naar PPS" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.pps", SaveFormat.Pps);

jpype.shutdownJVM()
```
