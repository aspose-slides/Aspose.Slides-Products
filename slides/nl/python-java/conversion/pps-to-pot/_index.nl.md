Om het bestand PPS naar POT te converteren, moet u een presentatie maken van het bestand PPS en dit opslaan als POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van PPS naar POT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.pot", SaveFormat.Pot);

jpype.shutdownJVM()
```
