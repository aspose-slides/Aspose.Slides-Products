Om het bestand ODP naar PPSM te converteren, moet u een presentatie maken van het bestand ODP en dit opslaan als PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-tutorial voor het converteren van ODP naar PPSM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.odp");

pres.save("output.ppsm", SaveFormat.Ppsm);

jpype.shutdownJVM()
```
