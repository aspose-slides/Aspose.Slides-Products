Om het bestand PPTX naar FODP te converteren, moet u een presentatie maken van het bestand PPTX en dit opslaan als FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js-code voor het converteren van PPTX naar FODP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.fodp", aspose.slides.SaveFormat.Fodp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
