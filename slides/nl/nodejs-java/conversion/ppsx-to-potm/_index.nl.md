Om het bestand PPSX naar POTM te converteren, moet u een presentatie maken van het bestand PPSX en dit opslaan als POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js-code voor het converteren van PPSX naar POTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.potm", aspose.slides.SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
