Om het bestand ODP naar POTX te converteren, moet u een presentatie maken van het bestand ODP en dit opslaan als POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js-code voor het converteren van ODP naar POTX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.potx", aspose.slides.SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
