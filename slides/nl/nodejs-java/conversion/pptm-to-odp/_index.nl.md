Om het bestand PPTM naar ODP te converteren, moet u een presentatie maken van het bestand PPTM en dit opslaan als ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js-code voor het converteren van PPTM naar ODP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.odp", aspose.slides.SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
