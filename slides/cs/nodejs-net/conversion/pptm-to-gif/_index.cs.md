Chcete-li převést PPTM do GIF, budete muset vytvořit prezentaci ze souboru PPTM a uložit ji jako GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod PPTM do GIF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.gif", SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
