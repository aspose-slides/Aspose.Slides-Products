Chcete-li převést FODP do PDF, budete muset vytvořit prezentaci ze souboru FODP a uložit ji jako PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod FODP do PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
