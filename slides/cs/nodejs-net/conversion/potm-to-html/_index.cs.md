Chcete-li převést POTM do HTML, budete muset vytvořit prezentaci ze souboru POTM a uložit ji jako HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod POTM do HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
