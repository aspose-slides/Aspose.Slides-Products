Chcete-li převést OTP do POT, budete muset vytvořit prezentaci ze souboru OTP a uložit ji jako POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod OTP do POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
