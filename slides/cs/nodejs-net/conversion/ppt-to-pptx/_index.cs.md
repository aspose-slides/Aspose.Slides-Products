Chcete-li převést PPT do PPTX, budete muset vytvořit prezentaci ze souboru PPT a uložit ji jako PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod PPT do PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
