Chcete-li převést OTP do PPTM, budete muset vytvořit prezentaci ze souboru OTP a uložit ji jako PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript kód pro převod OTP do PPTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pptm", SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
