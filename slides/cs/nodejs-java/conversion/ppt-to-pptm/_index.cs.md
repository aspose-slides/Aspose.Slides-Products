Chcete-li převést PPT do PPTM, budete muset vytvořit prezentaci ze souboru PPT a uložit ji jako PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kód Node.js pro převod PPT do PPTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
