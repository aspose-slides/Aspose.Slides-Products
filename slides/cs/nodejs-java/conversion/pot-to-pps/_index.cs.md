Chcete-li převést POT do PPS, budete muset vytvořit prezentaci ze souboru POT a uložit ji jako PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kód Node.js pro převod POT do PPS" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.pps", aspose.slides.SaveFormat.Pps);
}
finally
{
    if (pres != null) pres.dispose();
}
```
