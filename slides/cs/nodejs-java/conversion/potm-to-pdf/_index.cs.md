Chcete-li převést POTM do PDF, budete muset vytvořit prezentaci ze souboru POTM a uložit ji jako PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kód Node.js pro převod POTM do PDF" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.pdf", aspose.slides.SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
