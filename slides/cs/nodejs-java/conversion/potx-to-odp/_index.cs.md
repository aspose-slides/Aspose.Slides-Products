Chcete-li převést POTX do ODP, budete muset vytvořit prezentaci ze souboru POTX a uložit ji jako ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kód Node.js pro převod POTX do ODP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.odp", aspose.slides.SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
