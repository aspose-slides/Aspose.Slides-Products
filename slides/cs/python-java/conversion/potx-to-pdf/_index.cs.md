Chcete-li převést POTX do PDF, budete muset vytvořit prezentaci ze souboru POTX a uložit ji jako PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod POTX do PDF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.pdf", SaveFormat.Pdf);

jpype.shutdownJVM()
```
