Chcete-li převést PPTX do PPSM, budete muset vytvořit prezentaci ze souboru PPTX a uložit ji jako PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod PPTX do PPSM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptx");

pres.save("output.ppsm", SaveFormat.Ppsm);

jpype.shutdownJVM()
```
