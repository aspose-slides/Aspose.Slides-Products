Chcete-li převést PDF do PPSM, budete muset vytvořit prezentaci ze souboru PDF a uložit ji jako PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod PDF do PPSM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation();

pres.getSlides().removeAt(0);
pres.getSlides().addFromPdf("welcome-to-powerpoint.{format_from}");

pres.save("output.ppsm", SaveFormat.Ppsm);

jpype.shutdownJVM()

```
