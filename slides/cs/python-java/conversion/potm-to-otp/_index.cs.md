Chcete-li převést POTM do OTP, budete muset vytvořit prezentaci ze souboru POTM a uložit ji jako OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod POTM do OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
