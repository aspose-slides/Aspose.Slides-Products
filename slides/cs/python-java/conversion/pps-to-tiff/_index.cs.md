Chcete-li převést PPS do TIFF, budete muset vytvořit prezentaci ze souboru PPS a uložit ji jako TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod PPS do TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
