Chcete-li převést OTP do ODP, budete muset vytvořit prezentaci ze souboru OTP a uložit ji jako ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod OTP do ODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.odp", SaveFormat.Odp);

jpype.shutdownJVM()
```
