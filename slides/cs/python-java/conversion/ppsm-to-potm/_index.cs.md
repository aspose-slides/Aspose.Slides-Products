Chcete-li převést PPSM do POTM, budete muset vytvořit prezentaci ze souboru PPSM a uložit ji jako POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Výukový program Pythonu pro převod PPSM do POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
