Jak programově převedu HTML do PDF?

Pomocí [**Aspose.Slides for .NET**](https://products.aspose.com/slides/cs/net/) může každý vývojář nebo aplikace převést HTML do formátu PDF pomocí pouhých několika řádků kódu C#.

Jako moderní API pro zpracování dokumentů vytváří Aspose.Slides for .NET rychle soubory PDF ze stránek HTML. Knihovna Aspose PowerPoint vám umožňuje převádět HTML do PDF a mnoho dalších formátů souborů

Instalace Aspose.Slides: Otevřete správce balíčků [NuGet](https://www.nuget.org/packages/aspose.slides.net). Vyhledejte *Aspose.Slides* a nainstalujte jej.
 
Nebo můžete nainstalovat **Aspose.Slides** spuštěním tohoto příkazu z konzoly Správce balíčků.

```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromHtml("page.html");
    pres.Slides.RemoveAt(0); // remove default empty slide

    pres.Save("doc.pdf", SaveFormat.Pdf);
}
```
