Chcete-li převést HTML do TIFF, budete muset vytvořit prezentaci ze souboru HTML a uložit ji jako TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Java kód pro převod HTML do TIFF" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().removeAt(0);
    FileInputStream tr = new FileInputStream("file.html");
    pres.getSlides().addFromHtml(tr);
    pres.save("doc.tiff", SaveFormat.Tiff);
} finally {
    if (pres != null) pres.dispose();
}
```
