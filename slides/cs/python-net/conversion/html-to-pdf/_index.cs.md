Chcete-li převést HTML do PDF, budete muset vytvořit prezentaci ze souboru HTML a uložit ji jako PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python kód pro převod HTML do PDF" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("index.pdf", slides.export.SaveFormat.PDF)

```
