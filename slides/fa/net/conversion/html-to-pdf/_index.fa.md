چگونه HTML را به صورت برنامه نویسی به PDF تبدیل کنم؟

با استفاده از [**Aspose.Slides for .NET**](https://products.aspose.com/slides/fa/net/)، هر برنامه‌نویس یا برنامه‌ای می‌تواند HTML را تنها با چند خط کد C# به فرمت PDF تبدیل کند.

Aspose.Slides for .NET به عنوان یک API مدرن برای پردازش اسناد، فایل های PDF را از صفحات HTML به سرعت ایجاد می کند. کتابخانه Aspose PowerPoint به شما امکان می دهد HTML را به PDF و بسیاری از فرمت های فایل دیگر تبدیل کنید

برای نصب Aspose.Slides: مدیر بسته [NuGet](https://www.nuget.org/packages/aspose.slides.net) را باز کنید. *Aspose.Slides* را جستجو کرده و نصب کنید.
 
یا می توانید **Aspose.Slides** را با اجرای این دستور از کنسول Package Manager نصب کنید.
