چگونه PDF را در کد به XML تبدیل کنم؟

با استفاده از [**Aspose.Slides for.NET**](https://products.aspose.com/slides/fa/net/)، هر برنامه‌نویس یا برنامه‌ای می‌تواند تنها با چند خط کد C#، PDF را به فایل‌های XML تبدیل کند.

Aspose.Slides for .NET به عنوان یک API پردازش اسناد مدرن، صفحات PDF را به سرعت به XML صادر می کند. کتابخانه Aspose PowerPoint به شما امکان می دهد PDF را به XML و بسیاری از فرمت های فایل دیگر تبدیل کنید.

برای نصب Aspose.Slides: مدیر بسته [NuGet](https://www.nuget.org/packages/aspose.slides.net) را باز کنید. *Aspose.Slides* را جستجو کرده و نصب کنید.
 
یا می توانید **Aspose.Slides** را با اجرای این دستور از کنسول Package Manager نصب کنید.

```cs
using (Presentation pres = new Presentation())
    {
        pres.Slides.AddFromPdf("doc.pdf");
        pres.Slides.RemoveAt(0); // removes default empty slide

        for (var index = 0; index < pres.Slides.Count; index++)
        {
            ISlide slide = pres.Slides[index];
            using (FileStream stream = new FileStream($"doc-{index}.xml", FileMode.Create, FileAccess.Write))
            {
                slide.WriteAsSvg(stream);
            }
        }
    }
```
