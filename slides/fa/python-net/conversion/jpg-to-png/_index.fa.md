برای تبدیل JPG به PNG، باید Presentation را از فایل JPG ایجاد کنید و آن را به عنوان PNG ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="کد پایتون برای تبدیل JPG به PNG" >}}
```python

import aspose.slides as slides
import aspose.pydrawing as drawing

with slides.Presentation() as pres:
    slide = pres.slides[0]
    image = pres.images.add_image(drawing.Bitmap(dataDir+ "image.jpg"))
	slide.shapes.add_picture_frame(slides.ShapeType.RECTANGLE, 10, 10, 100, 100, image)
    for sld in pres.slides:
        bmp = sld.get_thumbnail(1, 1)
        bmp.save("Slide_{num}.png".format(num=str(sld.slide_number)), drawing.imaging.ImageFormat.png)

```
