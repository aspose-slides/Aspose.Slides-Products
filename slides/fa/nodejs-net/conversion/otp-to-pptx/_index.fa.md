برای تبدیل OTP به PPTX، باید Presentation را از فایل OTP ایجاد کنید و آن را به عنوان PPTX ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="کد جاوا اسکریپت برای تبدیل OTP به PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
