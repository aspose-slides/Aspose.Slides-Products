برای تبدیل PPSM به HTML، باید Presentation را از فایل PPSM ایجاد کنید و آن را به عنوان HTML ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="آموزش پایتون برای تبدیل PPSM به HTML" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
