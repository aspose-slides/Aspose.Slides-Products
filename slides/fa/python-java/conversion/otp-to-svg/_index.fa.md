برای تبدیل OTP به SVG، باید Presentation را از فایل OTP ایجاد کنید و آن را به عنوان SVG ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="آموزش پایتون برای تبدیل OTP به SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
