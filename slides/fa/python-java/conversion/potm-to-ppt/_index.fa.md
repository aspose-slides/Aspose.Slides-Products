برای تبدیل POTM به PPT، باید Presentation را از فایل POTM ایجاد کنید و آن را به عنوان PPT ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="آموزش پایتون برای تبدیل POTM به PPT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.ppt", SaveFormat.Ppt);

jpype.shutdownJVM()
```
