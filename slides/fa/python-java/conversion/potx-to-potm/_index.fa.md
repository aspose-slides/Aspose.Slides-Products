برای تبدیل POTX به POTM، باید Presentation را از فایل POTX ایجاد کنید و آن را به عنوان POTM ذخیره کنید.

{{< blocks/products/pf/slides-design-update-10-2026/code title="آموزش پایتون برای تبدیل POTX به POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
