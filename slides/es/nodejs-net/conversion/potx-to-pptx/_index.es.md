Para convertir POTX a PPTX, deberá crear una presentación a partir del archivo POTX y guardarla como PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para convertir POTX en PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
