Para convertir POT a HTML, deberá crear una presentación a partir del archivo POT y guardarla como HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para convertir POT en HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
