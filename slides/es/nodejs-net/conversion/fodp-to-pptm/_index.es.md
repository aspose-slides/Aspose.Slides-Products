Para convertir FODP a PPTM, deberá crear una presentación a partir del archivo FODP y guardarla como PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para convertir FODP en PPTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pptm", SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
