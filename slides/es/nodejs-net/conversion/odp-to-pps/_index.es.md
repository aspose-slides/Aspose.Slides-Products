Para convertir ODP a PPS, deberá crear una presentación a partir del archivo ODP y guardarla como PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para convertir ODP en PPS" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.pps", SaveFormat.Pps);
}
finally
{
    if (pres != null) pres.dispose();
}
```
