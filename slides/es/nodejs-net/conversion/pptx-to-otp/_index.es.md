Para convertir PPTX a OTP, deberá crear una presentación a partir del archivo PPTX y guardarla como OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para convertir PPTX en OTP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
