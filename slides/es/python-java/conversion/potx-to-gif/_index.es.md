Para convertir POTX a GIF, deberá crear una presentación a partir del archivo POTX y guardarla como GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir POTX en GIF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.gif", SaveFormat.Gif);

jpype.shutdownJVM()
```
