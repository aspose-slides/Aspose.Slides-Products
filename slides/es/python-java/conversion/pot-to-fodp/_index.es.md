Para convertir POT a FODP, deberá crear una presentación a partir del archivo POT y guardarla como FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir POT en FODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("output.fodp", SaveFormat.Fodp);

jpype.shutdownJVM()
```
