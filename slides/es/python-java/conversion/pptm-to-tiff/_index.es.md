Para convertir PPTM a TIFF, deberá crear una presentación a partir del archivo PPTM y guardarla como TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir PPTM en TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
