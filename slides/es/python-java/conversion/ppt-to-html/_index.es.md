Para convertir PPT a HTML, deberá crear una presentación a partir del archivo PPT y guardarla como HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir PPT en HTML" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
