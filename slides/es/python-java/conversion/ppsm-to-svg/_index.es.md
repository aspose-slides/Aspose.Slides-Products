Para convertir PPSM a SVG, deberá crear una presentación a partir del archivo PPSM y guardarla como SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir PPSM en SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
