Para convertir POTM a PPT, deberá crear una presentación a partir del archivo POTM y guardarla como PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir POTM en PPT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.ppt", SaveFormat.Ppt);

jpype.shutdownJVM()
```
