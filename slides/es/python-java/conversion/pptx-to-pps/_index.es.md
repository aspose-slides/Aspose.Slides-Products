Para convertir PPTX a PPS, deberá crear una presentación a partir del archivo PPTX y guardarla como PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir PPTX en PPS" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptx");

pres.save("output.pps", SaveFormat.Pps);

jpype.shutdownJVM()
```
