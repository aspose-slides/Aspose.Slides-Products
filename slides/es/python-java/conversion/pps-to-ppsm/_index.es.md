Para convertir PPS a PPSM, deberá crear una presentación a partir del archivo PPS y guardarla como PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir PPS en PPSM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.ppsm", SaveFormat.Ppsm);

jpype.shutdownJVM()
```
