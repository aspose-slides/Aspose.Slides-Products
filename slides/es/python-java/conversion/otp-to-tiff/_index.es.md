Para convertir OTP a TIFF, deberá crear una presentación a partir del archivo OTP y guardarla como TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial de Python para convertir OTP en TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
