{{< blocks/products/pf/slides-design-update-10-2026/code title="Código fuente de conversión Java de PPSX a SVG" >}}
```cs
// instantiate a Presentation object that represents a PPSX file
Presentation pres = new Presentation("template.ppsx");
try {
    // Access the first slide
    ISlide sld = pres.getSlides().get_Item(0);

    // Create a memory stream object
    FileOutputStream svgStream = new FileOutputStream("output.svg");

    // Create SVG image of slide and save in memory stream
    sld.writeAsSvg(svgStream);

    svgStream.close();
} catch (IOException e) {
} finally {
    pres.dispose();
}   

```
