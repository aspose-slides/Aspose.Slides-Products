Con [**Aspose.Slides for .NET**](https://products.aspose.com/slides/es/net/), puede fusionar archivos HTML rápidamente con solo unas pocas líneas de código

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código C# para fusionar HTML con HTML" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.RemoveAt(0); // removes default empty slide
    pres.Slides.AddFromHtml("page_1.html");
    pres.Slides.AddFromHtml("page_2.html");
    pres.Save("MergedFile.html", SaveFormat.Html);
}
```
