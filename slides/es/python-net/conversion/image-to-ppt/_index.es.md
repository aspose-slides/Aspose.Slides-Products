Para convertir la imagen a PPT, deberá crear una presentación a partir de un archivo de imagen y guardarla como PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código Python para convertir imagen en PPT" >}}
```python

import aspose.slides as slides
import aspose.pydrawing as drawing

with slides.Presentation() as pres:
    slide = pres.slides[0]
    image = pres.images.add_image(drawing.Bitmap(dataDir+ "image.png"))
	slide.shapes.add_picture_frame(slides.ShapeType.RECTANGLE, 0, 0, 720, 540, image)
    pres.save("index.ppt", slides.export.SaveFormat.PPT)

```
