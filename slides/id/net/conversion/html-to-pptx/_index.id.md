Menggunakan [**Aspose.Slides for .NET**](https://products.aspose.com/slides/id/net/), Anda dapat mengonversi dokumen HTML ke presentasi PowerPoint hanya dengan beberapa baris kode:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode C# untuk mengonversi HTML ke PPTX" >}}
```cs
using (var presentation = new Presentation())
{
    presentation.Slides.RemoveAt(0);
    using (var htmlStream = File.OpenRead("page.html"))
    {
        presentation.Slides.AddFromHtml(htmlStream);
    }

    presentation.Save("Presentation.pptx", SaveFormat.Pptx);
}
```
