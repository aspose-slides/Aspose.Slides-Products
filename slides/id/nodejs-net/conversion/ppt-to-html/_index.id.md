Untuk mengonversi PPT ke HTML, Anda perlu membuat Presentasi dari file PPT dan menyimpannya sebagai HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah PPT menjadi HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
