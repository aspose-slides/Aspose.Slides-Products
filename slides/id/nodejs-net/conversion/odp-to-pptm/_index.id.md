Untuk mengonversi ODP ke PPTM, Anda perlu membuat Presentasi dari file ODP dan menyimpannya sebagai PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah ODP menjadi PPTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.pptm", SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
