Untuk mengonversi POTX ke POTM, Anda perlu membuat Presentasi dari file POTX dan menyimpannya sebagai POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah POTX menjadi POTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.potm", SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
