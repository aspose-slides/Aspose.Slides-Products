Untuk mengonversi OTP ke PDF, Anda perlu membuat Presentasi dari file OTP dan menyimpannya sebagai PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah OTP menjadi PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
