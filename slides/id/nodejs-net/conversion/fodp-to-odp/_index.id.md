Untuk mengonversi FODP ke ODP, Anda perlu membuat Presentasi dari file FODP dan menyimpannya sebagai ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah FODP menjadi ODP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.odp", SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
