Untuk mengonversi PPS ke FODP, Anda perlu membuat Presentasi dari file PPS dan menyimpannya sebagai FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah PPS menjadi FODP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("output.fodp", SaveFormat.Fodp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
