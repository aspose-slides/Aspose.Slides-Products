Untuk mengonversi PDF ke PPTM, Anda perlu membuat Presentasi dari file PDF dan menyimpannya sebagai PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah PDF menjadi PPTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat, ShapeType } = asposeSlides;

var pres = new Presentation();
try
{
    pres.slides.removeAt(0);
    var slides = pres.slides.addFromPdf("welcome-to-powerpoint.pdf");

    pres.save("output.pptm", SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
} 

```
