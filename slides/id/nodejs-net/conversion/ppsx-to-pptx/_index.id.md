Untuk mengonversi PPSX ke PPTX, Anda perlu membuat Presentasi dari file PPSX dan menyimpannya sebagai PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode JavaScript untuk mengubah PPSX menjadi PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
