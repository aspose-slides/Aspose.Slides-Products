Untuk mengonversi PPTM ke OTP, Anda perlu membuat Presentasi dari file PPTM dan menyimpannya sebagai OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPTM menjadi OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
