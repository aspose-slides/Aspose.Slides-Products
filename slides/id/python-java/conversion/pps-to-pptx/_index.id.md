Untuk mengonversi PPS ke PPTX, Anda perlu membuat Presentasi dari file PPS dan menyimpannya sebagai PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPS menjadi PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
