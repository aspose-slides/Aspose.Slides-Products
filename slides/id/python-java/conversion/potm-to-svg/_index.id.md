Untuk mengonversi POTM ke SVG, Anda perlu membuat Presentasi dari file POTM dan menyimpannya sebagai SVG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah POTM menjadi SVG" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

for i in range(pres.getSlides().size()):
    outputStream = open('slide" + i + ".svg', "wb")
    outputStream.write(Slide.writeAsSvgToBytes(pres.getSlides().get_Item(i)))

jpype.shutdownJVM()
```
