Untuk mengonversi PPSX ke POTX, Anda perlu membuat Presentasi dari file PPSX dan menyimpannya sebagai POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPSX menjadi POTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

pres.save("output.potx", SaveFormat.Potx);

jpype.shutdownJVM()
```
