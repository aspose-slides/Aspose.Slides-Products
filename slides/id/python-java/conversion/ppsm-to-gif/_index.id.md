Untuk mengonversi PPSM ke GIF, Anda perlu membuat Presentasi dari file PPSM dan menyimpannya sebagai GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPSM menjadi GIF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.gif", SaveFormat.Gif);

jpype.shutdownJVM()
```
