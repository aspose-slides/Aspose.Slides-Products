Untuk mengonversi PPT ke POTX, Anda perlu membuat Presentasi dari file PPT dan menyimpannya sebagai POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPT menjadi POTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("output.potx", SaveFormat.Potx);

jpype.shutdownJVM()
```
