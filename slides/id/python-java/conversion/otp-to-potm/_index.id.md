Untuk mengonversi OTP ke POTM, Anda perlu membuat Presentasi dari file OTP dan menyimpannya sebagai POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah OTP menjadi POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
