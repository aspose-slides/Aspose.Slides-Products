Untuk mengonversi PPTM ke FODP, Anda perlu membuat Presentasi dari file PPTM dan menyimpannya sebagai FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python untuk mengubah PPTM menjadi FODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.fodp", SaveFormat.Fodp);

jpype.shutdownJVM()
```
