Untuk mengonversi HTML ke TIFF, Anda perlu membuat Presentasi dari file HTML dan menyimpannya sebagai TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode python untuk mengubah HTML menjadi TIFF" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("doc.tiff", slides.export.SaveFormat.TIFF)

```
