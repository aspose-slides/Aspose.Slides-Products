Untuk mengonversi Image ke JPG, Anda perlu membuat Presentasi dari file Image dan menyimpannya sebagai JPG.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode python untuk mengubah Image menjadi JPG" >}}
```python

import aspose.slides as slides
import aspose.pydrawing as drawing

with slides.Presentation() as pres:
    slide = pres.slides[0]
    image = pres.images.add_image(drawing.Bitmap(dataDir+ "image.png"))
	slide.shapes.add_picture_frame(slides.ShapeType.RECTANGLE, 10, 10, 100, 100, image)
    for sld in pres.slides:
        bmp = sld.get_thumbnail(1, 1)
        bmp.save("Slide_{num}.jpg".format(num=str(sld.slide_number)), drawing.imaging.ImageFormat.jpeg)

```
