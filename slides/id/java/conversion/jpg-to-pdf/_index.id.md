Untuk mengonversi JPG ke PDF, Anda perlu membuat Presentasi dari file JPG dan menyimpannya sebagai PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Java untuk mengonversi JPG menjadi PDF" >}}
```java

Presentation pres = new Presentation();
try {
    ISlide slide = pres.getSlides().get_Item(0);
	IPPImage image = pres.getImages().addImage(Files.readAllBytes(Paths.get("image.jpg")));
	slide.getShapes().addPictureFrame(ShapeType.Rectangle, 10, 10, 100, 100, image);
    pres.save("index.pdf", SaveFormat.Pdf);
} finally {
    if (pres != null) pres.dispose();
}
```
