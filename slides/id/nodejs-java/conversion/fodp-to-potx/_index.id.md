Untuk mengonversi FODP ke POTX, Anda perlu membuat Presentasi dari file FODP dan menyimpannya sebagai POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah FODP menjadi POTX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.potx", aspose.slides.SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
