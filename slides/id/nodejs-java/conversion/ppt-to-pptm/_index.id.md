Untuk mengonversi PPT ke PPTM, Anda perlu membuat Presentasi dari file PPT dan menyimpannya sebagai PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah PPT menjadi PPTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
