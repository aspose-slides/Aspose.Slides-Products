Untuk mengonversi PPTM ke FODP, Anda perlu membuat Presentasi dari file PPTM dan menyimpannya sebagai FODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah PPTM menjadi FODP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.fodp", aspose.slides.SaveFormat.Fodp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
