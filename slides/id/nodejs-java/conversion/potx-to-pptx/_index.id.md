Untuk mengonversi POTX ke PPTX, Anda perlu membuat Presentasi dari file POTX dan menyimpannya sebagai PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah POTX menjadi PPTX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.pptx", aspose.slides.SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
