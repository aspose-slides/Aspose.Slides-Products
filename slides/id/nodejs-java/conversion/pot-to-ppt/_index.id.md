Untuk mengonversi POT ke PPT, Anda perlu membuat Presentasi dari file POT dan menyimpannya sebagai PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah POT menjadi PPT" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.ppt", aspose.slides.SaveFormat.Ppt);
}
finally
{
    if (pres != null) pres.dispose();
}
```
