Untuk mengonversi POTX ke PPS, Anda perlu membuat Presentasi dari file POTX dan menyimpannya sebagai PPS.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Kode Node.js untuk mengubah POTX menjadi PPS" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.pps", aspose.slides.SaveFormat.Pps);
}
finally
{
    if (pres != null) pres.dispose();
}
```
