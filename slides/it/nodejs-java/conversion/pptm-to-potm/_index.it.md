Per convertire PPTM in POTM, dovrai creare la presentazione dal file PPTM e salvarla come POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Node.js per convertire PPTM in POTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.potm", aspose.slides.SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
