Per convertire POT in PPSM, dovrai creare la presentazione dal file POT e salvarla come PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Node.js per convertire POT in PPSM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.ppsm", aspose.slides.SaveFormat.Ppsm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
