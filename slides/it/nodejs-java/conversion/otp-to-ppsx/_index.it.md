Per convertire OTP in PPSX, dovrai creare la presentazione dal file OTP e salvarla come PPSX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Node.js per convertire OTP in PPSX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.ppsx", aspose.slides.SaveFormat.Ppsx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
