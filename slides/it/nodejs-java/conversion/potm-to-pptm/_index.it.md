Per convertire POTM in PPTM, dovrai creare la presentazione dal file POTM e salvarla come PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Node.js per convertire POTM in PPTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
