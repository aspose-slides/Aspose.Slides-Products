Per convertire PPSX in POTX, dovrai creare la presentazione dal file PPSX e salvarla come POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Node.js per convertire PPSX in POTX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.potx", aspose.slides.SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
