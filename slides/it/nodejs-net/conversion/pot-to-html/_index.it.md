Per convertire POT in HTML, dovrai creare la presentazione dal file POT e salvarla come HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire POT in HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
