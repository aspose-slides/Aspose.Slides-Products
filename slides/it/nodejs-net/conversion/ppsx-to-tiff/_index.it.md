Per convertire PPSX in TIFF, dovrai creare la presentazione dal file PPSX e salvarla come TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire PPSX in TIFF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.tiff", SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
