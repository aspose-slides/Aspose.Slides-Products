Per convertire PPSM in POT, dovrai creare la presentazione dal file PPSM e salvarla come POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire PPSM in POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsm");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
