Per convertire PPS in PDF, dovrai creare la presentazione dal file PPS e salvarla come PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire PPS in PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
