Per convertire POT in PDF, dovrai creare la presentazione dal file POT e salvarla come PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire POT in PDF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.pdf", SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
