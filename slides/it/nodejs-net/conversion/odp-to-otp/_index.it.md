Per convertire ODP in OTP, dovrai creare la presentazione dal file ODP e salvarla come OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice JavaScript per convertire ODP in OTP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
