Per convertire PPT in POT, dovrai creare la presentazione dal file PPT e salvarla come POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire PPT in POT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("output.pot", SaveFormat.Pot);

jpype.shutdownJVM()
```
