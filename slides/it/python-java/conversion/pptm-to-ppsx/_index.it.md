Per convertire PPTM in PPSX, dovrai creare la presentazione dal file PPTM e salvarla come PPSX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire PPTM in PPSX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.ppsx", SaveFormat.Ppsx);

jpype.shutdownJVM()
```
