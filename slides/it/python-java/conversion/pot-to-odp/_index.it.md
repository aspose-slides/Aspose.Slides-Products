Per convertire POT in ODP, dovrai creare la presentazione dal file POT e salvarla come ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire POT in ODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("output.odp", SaveFormat.Odp);

jpype.shutdownJVM()
```
