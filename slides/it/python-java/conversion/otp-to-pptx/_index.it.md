Per convertire OTP in PPTX, dovrai creare la presentazione dal file OTP e salvarla come PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire OTP in PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
