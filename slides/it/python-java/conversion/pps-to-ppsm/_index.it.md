Per convertire PPS in PPSM, dovrai creare la presentazione dal file PPS e salvarla come PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire PPS in PPSM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.ppsm", SaveFormat.Ppsm);

jpype.shutdownJVM()
```
