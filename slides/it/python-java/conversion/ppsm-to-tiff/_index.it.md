Per convertire PPSM in TIFF, dovrai creare la presentazione dal file PPSM e salvarla come TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python per convertire PPSM in TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
