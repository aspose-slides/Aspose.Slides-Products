Usando [**Aspose.Slides per .NET**](https://products.aspose.com/slides/it/net/), puoi convertire un PDF in una presentazione PowerPoint con poche righe di codice:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice C# per convertire PDF in PPTX" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromPdf("InputPDF.pdf");
    pres.Save("OutputPresentation.pptx", SaveFormat.Pptx);
}
```
