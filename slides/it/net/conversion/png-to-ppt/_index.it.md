Usando [**Aspose.Slides per .NET**](https://products.aspose.com/slides/it/net/), puoi convertire un'immagine PNG in una presentazione PowerPoint con poche righe di codice:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice C# per convertire PNG in PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    IPPImage image = pres.Images.AddImage(File.ReadAllBytes("image.png"));
    pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);
    pres.Save("Presentation.ppt", SaveFormat.Ppt);
}
```
