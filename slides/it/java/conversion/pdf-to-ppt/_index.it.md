Per convertire PDF in PPT, dovrai creare una presentazione dal file PDF e salvarla come PPT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice Java per convertire PDF in PPT" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    pres.save("OutputPresentation.ppt", SaveFormat.Ppt);
} finally {
    if (pres != null) pres.dispose();
}
```
