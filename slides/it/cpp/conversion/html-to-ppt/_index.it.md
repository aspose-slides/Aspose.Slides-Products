Usando [**Aspose.Slides per C++**](https://products.aspose.com/slides/it/cpp/), puoi convertire un documento HTML in una presentazione PowerPoint con poche righe di codice:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Codice C++ per convertire HTML in PPT" >}}
```cpp
auto presentation = System::MakeObject<Presentation>();
presentation->get_Slides()->RemoveAt(0);

{
    auto htmlStream = System::IO::File::OpenRead(u"page.html");
    presentation->get_Slides()->AddFromHtml(htmlStream);
}

presentation->Save(u"MyPresentation.ppt", SaveFormat::Ppt);
```
