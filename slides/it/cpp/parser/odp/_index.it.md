Usa Aspose.Slides for C++ per analizzare file di presentazione ODP ed estrarre il testo dalle diapositive. L'API espone il testo delle diapositive tramite `SlideUtil::GetAllTextBoxes`, `ITextFrame`, `IParagraph` e `IPortion`, così puoi leggere il contenuto testuale senza automatizzare Microsoft PowerPoint. Installa il pacchetto [`Aspose.Slides.Cpp`](https://www.nuget.org/packages/Aspose.Slides.Cpp/) da NuGet oppure usa il comando seguente nella Console di Gestione pacchetti.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Analizzare file ODP – C++" >}}
```cpp
auto presentation = MakeObject<Presentation>(u"presentation.odp");
auto textFrames = SlideUtil::GetAllTextBoxes(presentation->get_Slide(0));

for (auto&& textFrame : textFrames)
{
    for (auto&& paragraph : textFrame->get_Paragraphs())
    {
        for (auto&& portion : paragraph->get_Portions())
        {
            Console::WriteLine(portion->get_Text());
        }
    }
}

presentation->Dispose();
```
