Genom att använda [**Aspose.Slides for .NET**](https://products.aspose.com/slides/sv/net/) kan du snabbt slå samman PDF-filer med bara några rader kod

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-kod för att slå samman PDF till PDF" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.RemoveAt(0); // removes default empty slide
    pres.Slides.AddFromPdf("firstFile.pdf");
    pres.Slides.AddFromPdf("secondFile.pdf");

    pres.Save("MergedFile.pdf", SaveFormat.Pdf);
}
```
