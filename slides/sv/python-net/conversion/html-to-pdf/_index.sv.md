För att konvertera HTML till PDF måste du skapa en presentation från filen HTML och spara den som PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-kod för att konvertera HTML till PDF" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("index.pdf", slides.export.SaveFormat.PDF)

```
