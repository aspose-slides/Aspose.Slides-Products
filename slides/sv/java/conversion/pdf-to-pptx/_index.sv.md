För att konvertera PDF till PPTX måste du skapa en presentation från filen PDF och spara den som PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Java-kod för att konvertera PDF till PPTX" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    pres.save("OutputPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
