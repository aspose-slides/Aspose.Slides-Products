För att konvertera POTX till POTM måste du skapa en presentation från filen POTX och spara den som POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera POTX till POTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.potm", SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
