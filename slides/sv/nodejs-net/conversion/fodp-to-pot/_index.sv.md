För att konvertera FODP till POT måste du skapa en presentation från filen FODP och spara den som POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera FODP till POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
