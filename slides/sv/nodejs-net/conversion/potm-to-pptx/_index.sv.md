För att konvertera POTM till PPTX måste du skapa en presentation från filen POTM och spara den som PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera POTM till PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
