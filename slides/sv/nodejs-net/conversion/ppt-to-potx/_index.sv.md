För att konvertera PPT till POTX måste du skapa en presentation från filen PPT och spara den som POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera PPT till POTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.potx", SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
