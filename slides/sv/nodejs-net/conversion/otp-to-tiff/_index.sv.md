För att konvertera OTP till TIFF måste du skapa en presentation från filen OTP och spara den som TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera OTP till TIFF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.tiff", SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
