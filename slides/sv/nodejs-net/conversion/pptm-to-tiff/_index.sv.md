För att konvertera PPTM till TIFF måste du skapa en presentation från filen PPTM och spara den som TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera PPTM till TIFF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.tiff", SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
