För att konvertera PPTX till PPSM måste du skapa en presentation från filen PPTX och spara den som PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-kod för att konvertera PPTX till PPSM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.ppsm", SaveFormat.Ppsm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
