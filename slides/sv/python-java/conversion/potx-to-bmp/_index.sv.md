För att konvertera POTX till BMP måste du skapa en presentation från filen POTX och spara den som BMP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera POTX till BMP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

for i in range(pres.getSlides().size()):
    buffImage = pres.getSlides().get_Item(i).getThumbnail(2, 2)
    ImageIO.write(buffImage, "BMP", File("slide" + str(i) + ".bmp"))

jpype.shutdownJVM()
```
