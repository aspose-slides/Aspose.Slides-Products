För att konvertera PPTM till TIFF måste du skapa en presentation från filen PPTM och spara den som TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera PPTM till TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
