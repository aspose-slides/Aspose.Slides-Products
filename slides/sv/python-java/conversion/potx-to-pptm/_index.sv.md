För att konvertera POTX till PPTM måste du skapa en presentation från filen POTX och spara den som PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera POTX till PPTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.pptm", SaveFormat.Pptm);

jpype.shutdownJVM()
```
