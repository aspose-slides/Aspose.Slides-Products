För att konvertera FODP till ODP måste du skapa en presentation från filen FODP och spara den som ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera FODP till ODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.fodp");

pres.save("output.odp", SaveFormat.Odp);

jpype.shutdownJVM()
```
