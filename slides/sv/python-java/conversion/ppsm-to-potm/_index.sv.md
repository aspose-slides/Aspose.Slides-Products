För att konvertera PPSM till POTM måste du skapa en presentation från filen PPSM och spara den som POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera PPSM till POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
