För att konvertera PPT till HTML måste du skapa en presentation från filen PPT och spara den som HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera PPT till HTML" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
