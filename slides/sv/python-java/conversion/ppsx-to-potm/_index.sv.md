För att konvertera PPSX till POTM måste du skapa en presentation från filen PPSX och spara den som POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera PPSX till POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
