För att konvertera POTM till PPSX måste du skapa en presentation från filen POTM och spara den som PPSX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python handledning för att konvertera POTM till PPSX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.ppsx", SaveFormat.Ppsx);

jpype.shutdownJVM()
```
