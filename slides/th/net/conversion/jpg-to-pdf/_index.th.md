ฉันจะแปลง JPG เป็น PDF โดยทางโปรแกรมได้อย่างไร

การใช้ [**Aspose.Slides for .NET**](https://products.aspose.com/slides/th/net/) นักพัฒนาซอฟต์แวร์หรือแอปพลิเคชันใดๆ สามารถแปลง JPG เป็นรูปแบบ PDF ด้วยโค้ด C# เพียงไม่กี่บรรทัด

ในฐานะที่เป็น API การประมวลผลเอกสารที่ทันสมัย ​​Aspose.Slides for .NET จะสร้างไฟล์ PDF จากภาพ JPG ได้อย่างรวดเร็ว ห้องสมุด Aspose PowerPoint ช่วยให้คุณสามารถแปลง JPG เป็น PDF และรูปแบบไฟล์อื่น ๆ อีกมากมาย

ในการติดตั้ง Aspose.Slides: เปิดตัวจัดการแพ็คเกจ [NuGet](https://www.nuget.org/packages/aspose.slides.net) ค้นหา Aspose.Slides และติดตั้ง
 
หรือคุณสามารถติดตั้ง **Aspose.Slides** โดยเรียกใช้คำสั่งนี้จาก Package Manager Console
