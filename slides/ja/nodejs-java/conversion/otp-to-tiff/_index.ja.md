OTP を TIFF に変換するには、OTP ファイルからプレゼンテーションを作成し、それを TIFF として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="OTP を TIFF に変換するための Node.js コード" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.tiff", aspose.slides.SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
