PPSX を ODP に変換するには、PPSX ファイルからプレゼンテーションを作成し、それを ODP として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPSX を ODP に変換するための Node.js コード" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.odp", aspose.slides.SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
