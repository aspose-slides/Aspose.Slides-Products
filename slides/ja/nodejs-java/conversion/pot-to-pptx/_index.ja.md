POT を PPTX に変換するには、POT ファイルからプレゼンテーションを作成し、それを PPTX として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="POT を PPTX に変換するための Node.js コード" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.pptx", aspose.slides.SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
