FODP を PDF に変換するには、FODP ファイルからプレゼンテーションを作成し、それを PDF として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="FODP を PDF に変換するための Node.js コード" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.pdf", aspose.slides.SaveFormat.Pdf);
}
finally
{
    if (pres != null) pres.dispose();
}
```
