PPS を PPT に変換するには、PPS ファイルからプレゼンテーションを作成し、それを PPT として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPS を PPT に変換するための JavaScript コード" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("output.ppt", SaveFormat.Ppt);
}
finally
{
    if (pres != null) pres.dispose();
}
```
