POTM を HTML に変換するには、POTM ファイルからプレゼンテーションを作成し、それを HTML として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="POTM を HTML に変換するための JavaScript コード" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
