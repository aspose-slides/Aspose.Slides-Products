PPSX を GIF に変換するには、PPSX ファイルからプレゼンテーションを作成し、それを GIF として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPSX を GIF に変換するための JavaScript コード" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppsx");
try
{
    pres.save("output.gif", SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
