POT を HTML に変換するには、POT ファイルからプレゼンテーションを作成し、それを HTML として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="POT を HTML に変換するための Python チュートリアル" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
