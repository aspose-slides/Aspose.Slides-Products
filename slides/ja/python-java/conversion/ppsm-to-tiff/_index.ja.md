PPSM を TIFF に変換するには、PPSM ファイルからプレゼンテーションを作成し、それを TIFF として保存する必要があります。

{{< blocks/products/pf/slides-design-update-10-2026/code title="PPSM を TIFF に変換するための Python チュートリアル" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
