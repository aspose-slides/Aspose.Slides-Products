Para converter PPS para PPSM, você precisará criar uma apresentação a partir do arquivo PPS e salvá-la como PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter PPS em PPSM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pps");
try
{
    pres.save("output.ppsm", SaveFormat.Ppsm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
