Para converter PPTM para PPSM, você precisará criar uma apresentação a partir do arquivo PPTM e salvá-la como PPSM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter PPTM em PPSM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptm");
try
{
    pres.save("output.ppsm", SaveFormat.Ppsm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
