Para converter FODP para POTM, você precisará criar uma apresentação a partir do arquivo FODP e salvá-la como POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter FODP em POTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.potm", SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
