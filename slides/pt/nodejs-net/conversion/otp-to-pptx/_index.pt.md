Para converter OTP para PPTX, você precisará criar uma apresentação a partir do arquivo OTP e salvá-la como PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter OTP em PPTX" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.otp");
try
{
    pres.save("output.pptx", SaveFormat.Pptx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
