Para converter PPT para OTP, você precisará criar uma apresentação a partir do arquivo PPT e salvá-la como OTP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter PPT em OTP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.otp", SaveFormat.Otp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
