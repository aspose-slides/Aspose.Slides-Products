Para converter PPTX para POT, você precisará criar uma apresentação a partir do arquivo PPTX e salvá-la como POT.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter PPTX em POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
