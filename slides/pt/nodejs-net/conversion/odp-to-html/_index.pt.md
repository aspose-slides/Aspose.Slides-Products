Para converter ODP para HTML, você precisará criar uma apresentação a partir do arquivo ODP e salvá-la como HTML.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter ODP em HTML" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("pres.html", SaveFormat.Html);
}
finally
{
    if (pres != null) pres.dispose();
}
```
