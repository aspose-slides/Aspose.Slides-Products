Para converter POT para GIF, você precisará criar uma apresentação a partir do arquivo POT e salvá-la como GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código JavaScript para converter POT em GIF" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.pot");
try
{
    pres.save("output.gif", SaveFormat.Gif);
}
finally
{
    if (pres != null) pres.dispose();
}
```
