Para converter FODP para POTM, você precisará criar uma apresentação a partir do arquivo FODP e salvá-la como POTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python para converter FODP em POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.fodp");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
