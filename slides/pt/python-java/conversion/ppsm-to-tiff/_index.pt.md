Para converter PPSM para TIFF, você precisará criar uma apresentação a partir do arquivo PPSM e salvá-la como TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python para converter PPSM em TIFF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsm");

pres.save("output.tiff", SaveFormat.Tiff);

jpype.shutdownJVM()
```
