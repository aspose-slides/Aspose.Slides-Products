Para converter OTP para PPTX, você precisará criar uma apresentação a partir do arquivo OTP e salvá-la como PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python para converter OTP em PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
