Para converter PPT para PPTM, você precisará criar uma apresentação a partir do arquivo PPT e salvá-la como PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Tutorial Python para converter PPT em PPTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("output.pptm", SaveFormat.Pptm);

jpype.shutdownJVM()
```
