Usando [**Aspose.Slides para .NET**](https://products.aspose.com/slides/pt/net/), você pode converter PDF em apresentação do PowerPoint com apenas algumas linhas de código:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código C# para converter PDF para PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromPdf("InputPDF.pdf");
    pres.Save("OutputPresentation.ppt", SaveFormat.Ppt);
}
```
