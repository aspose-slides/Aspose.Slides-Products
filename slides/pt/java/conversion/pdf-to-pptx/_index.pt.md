Para converter o PDF para PPTX, você precisará criar a apresentação do arquivo PDF e salvá-lo como PPTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código Java para converter PDF em PPTX" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    pres.save("OutputPresentation.pptx", SaveFormat.Pptx);
} finally {
    if (pres != null) pres.dispose();
}
```
