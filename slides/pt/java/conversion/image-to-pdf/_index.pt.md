Para converter o Image para PDF, você precisará criar a apresentação do arquivo Image e salvá-lo como PDF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Código Java para converter Image em PDF" >}}
```java

Presentation pres = new Presentation();
try {
    ISlide slide = pres.getSlides().get_Item(0);
	IPPImage image = pres.getImages().addImage(Files.readAllBytes(Paths.get("image.png")));
	slide.getShapes().addPictureFrame(ShapeType.Rectangle, 10, 10, 100, 100, image);
    pres.save("index.pdf", SaveFormat.Pdf);
} finally {
    if (pres != null) pres.dispose();
}
```
