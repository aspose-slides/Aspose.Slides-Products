使用 [**Aspose.Slides for .NET**](https://products.aspose.com/slides/zh-hant/net/)，您只需幾行代碼即可向 PDF 文檔添加新的文本行。

{{< blocks/products/pf/slides-design-update-10-2026/code title="用於編輯 PDF 的 C# 代碼" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.RemoveAt(0); // remove default empty slide
    pres.Slides.AddFromPdf("doc.pdf");

    AutoShape shape = (AutoShape)pres.Slides[0].Shapes[0];
    shape.TextFrame.Text = "New text";

    pres.Save("doc.pdf", SaveFormat.Pdf);
}
```
