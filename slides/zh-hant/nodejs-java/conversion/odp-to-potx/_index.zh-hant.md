要將 ODP 轉換為 POTX，您需要從 ODP 文件創建演示文稿並將其另存為 POTX。

{{< blocks/products/pf/slides-design-update-10-2026/code title="用於將 ODP 轉換為 POTX 的 Node.js 代碼" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.odp");
try
{
    pres.save("output.potx", aspose.slides.SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
