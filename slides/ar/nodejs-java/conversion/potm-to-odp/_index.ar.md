لتحويل POTM إلى ODP، ستحتاج إلى إنشاء عرض تقديمي من ملف POTM وحفظه باسم ODP.

{{< blocks/products/pf/slides-design-update-10-2026/code title="كود Node.js لتحويل POTM إلى ODP" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.potm");
try
{
    pres.save("output.odp", aspose.slides.SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
