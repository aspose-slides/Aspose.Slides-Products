لتحويل PPSM إلى POTX، ستحتاج إلى إنشاء عرض تقديمي من ملف PPSM وحفظه باسم POTX.

{{< blocks/products/pf/slides-design-update-10-2026/code title="كود Node.js لتحويل PPSM إلى POTX" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsm");
try
{
    pres.save("output.potx", aspose.slides.SaveFormat.Potx);
}
finally
{
    if (pres != null) pres.dispose();
}
```
