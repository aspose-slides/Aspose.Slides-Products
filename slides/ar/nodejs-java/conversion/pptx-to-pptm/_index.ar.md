لتحويل PPTX إلى PPTM، ستحتاج إلى إنشاء عرض تقديمي من ملف PPTX وحفظه باسم PPTM.

{{< blocks/products/pf/slides-design-update-10-2026/code title="كود Node.js لتحويل PPTX إلى PPTM" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.pptx");
try
{
    pres.save("output.pptm", aspose.slides.SaveFormat.Pptm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
