لتحويل PPSM إلى TIFF، ستحتاج إلى إنشاء عرض تقديمي من ملف PPSM وحفظه باسم TIFF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="كود Node.js لتحويل PPSM إلى TIFF" >}}
```javascript

var aspose = aspose || {};

aspose.slides = require("aspose.slides.via.java");

var pres = new aspose.slides.Presentation("welcome-to-powerpoint.ppsm");
try
{
    pres.save("output.tiff", aspose.slides.SaveFormat.Tiff);
}
finally
{
    if (pres != null) pres.dispose();
}
```
