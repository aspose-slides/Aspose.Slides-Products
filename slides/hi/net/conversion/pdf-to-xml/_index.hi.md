मैं कोड में पीडीएफ को एक्सएमएल में कैसे बदलूं?

[**Aspose.Slides for .NET**](https://products.aspose.com/slides/hi/net/) का उपयोग करके, कोई भी डेवलपर या एप्लिकेशन पीडीएफ को एक्सएमएल फाइलों में सी# कोड की कुछ पंक्तियों के साथ परिवर्तित कर सकता है।

एक आधुनिक दस्तावेज़ संसाधन API के रूप में, Aspose.Slides .NET के लिए PDF पृष्ठों को XML को शीघ्रता से निर्यात करता है। एस्पोज पॉवरपॉइंट लाइब्रेरी आपको पीडीएफ को एक्सएमएल और कई अन्य फाइल फॉर्मेट में बदलने की अनुमति देती है।

Aspose.Slides स्थापित करने के लिए: [NuGet](https://www.nuget.org/packages/aspose.slides.net) पैकेज मैनेजर खोलें। *Aspose.Slides* खोजें और इसे इंस्टॉल करें।
 
या आप पैकेज मैनेजर कंसोल से इस कमांड को चलाकर **Aspose.Slides** इंस्टॉल कर सकते हैं।

using (Presentation pres = new Presentation())
    {
        pres.Slides.AddFromPdf("doc.pdf");
        pres.Slides.RemoveAt(0); // removes default empty slide

        for (var index = 0; index < pres.Slides.Count; index++)
        {
            ISlide slide = pres.Slides[index];
            using (FileStream stream = new FileStream($"doc-{index}.xml", FileMode.Create, FileAccess.Write))
            {
                slide.WriteAsSvg(stream);
            }
        }
    }
