Um das PPTX in HTML zu konvertieren, müssen Sie eine Präsentation aus der PPTX-Datei erstellen und diese als HTML speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von PPTX in HTML" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptx");

pres.save("pres.html", SaveFormat.Html);

jpype.shutdownJVM()
```
