Um das PPSX in ODP zu konvertieren, müssen Sie eine Präsentation aus der PPSX-Datei erstellen und diese als ODP speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von PPSX in ODP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppsx");

pres.save("output.odp", SaveFormat.Odp);

jpype.shutdownJVM()
```
