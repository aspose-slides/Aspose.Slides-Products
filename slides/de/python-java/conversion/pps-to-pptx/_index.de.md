Um das PPS in PPTX zu konvertieren, müssen Sie eine Präsentation aus der PPS-Datei erstellen und diese als PPTX speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von PPS in PPTX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pps");

pres.save("output.pptx", SaveFormat.Pptx);

jpype.shutdownJVM()
```
