Um das ODP in PPT zu konvertieren, müssen Sie eine Präsentation aus der ODP-Datei erstellen und diese als PPT speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von ODP in PPT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.odp");

pres.save("output.ppt", SaveFormat.Ppt);

jpype.shutdownJVM()
```
