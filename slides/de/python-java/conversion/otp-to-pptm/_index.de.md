Um das OTP in PPTM zu konvertieren, müssen Sie eine Präsentation aus der OTP-Datei erstellen und diese als PPTM speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von OTP in PPTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.pptm", SaveFormat.Pptm);

jpype.shutdownJVM()
```
