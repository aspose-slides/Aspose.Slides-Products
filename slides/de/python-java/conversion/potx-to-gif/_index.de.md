Um das POTX in GIF zu konvertieren, müssen Sie eine Präsentation aus der POTX-Datei erstellen und diese als GIF speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von POTX in GIF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potx");

pres.save("output.gif", SaveFormat.Gif);

jpype.shutdownJVM()
```
