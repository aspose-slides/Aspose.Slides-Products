Um das POT in PPSX zu konvertieren, müssen Sie eine Präsentation aus der POT-Datei erstellen und diese als PPSX speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von POT in PPSX" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pot");

pres.save("output.ppsx", SaveFormat.Ppsx);

jpype.shutdownJVM()
```
