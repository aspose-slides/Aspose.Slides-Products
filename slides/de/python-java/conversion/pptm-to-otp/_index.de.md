Um das PPTM in OTP zu konvertieren, müssen Sie eine Präsentation aus der PPTM-Datei erstellen und diese als OTP speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von PPTM in OTP" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.pptm");

pres.save("output.otp", SaveFormat.Otp);

jpype.shutdownJVM()
```
