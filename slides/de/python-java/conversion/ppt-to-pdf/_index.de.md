Um das PPT in PDF zu konvertieren, müssen Sie eine Präsentation aus der PPT-Datei erstellen und diese als PDF speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von PPT in PDF" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.ppt");

pres.save("output.pdf", SaveFormat.Pdf);

jpype.shutdownJVM()
```
