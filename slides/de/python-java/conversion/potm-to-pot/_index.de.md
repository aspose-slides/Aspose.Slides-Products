Um das POTM in POT zu konvertieren, müssen Sie eine Präsentation aus der POTM-Datei erstellen und diese als POT speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von POTM in POT" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.potm");

pres.save("output.pot", SaveFormat.Pot);

jpype.shutdownJVM()
```
