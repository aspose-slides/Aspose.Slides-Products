Um das OTP in POTM zu konvertieren, müssen Sie eine Präsentation aus der OTP-Datei erstellen und diese als POTM speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Tutorial zum Konvertieren von OTP in POTM" >}}
```python

import jpype
import asposeslides

jpype.startJVM()

from asposeslides.api import Presentation, SaveFormat
from javax.imageio import ImageIO
from java.io import File

pres = Presentation("PowerPoint.otp");

pres.save("output.potm", SaveFormat.Potm);

jpype.shutdownJVM()
```
