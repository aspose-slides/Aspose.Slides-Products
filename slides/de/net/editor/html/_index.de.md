Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) können Sie mit nur wenigen Codezeilen eine neue Textzeile zu einem HTML-Dokument hinzufügen.

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-Code zum Bearbeiten von HTML" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.RemoveAt(0); // removes default empty slide
    pres.Slides.AddFromHtml("page.html");

    AutoShape shape = (AutoShape)pres.Slides[0].Shapes[0];
    shape.TextFrame.Text = "New text";

    pres.Save("page.html", SaveFormat.Html);
}
```
