Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) können Sie mit nur wenigen Codezeilen ein HTML-Dokument in eine PowerPoint-Präsentation konvertieren:

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-Code zum Konvertieren von HTML in PPTX" >}}
```cs
using (var presentation = new Presentation())
{
    presentation.Slides.RemoveAt(0);
    using (var htmlStream = File.OpenRead("page.html"))
    {
        presentation.Slides.AddFromHtml(htmlStream);
    }

    presentation.Save("Presentation.pptx", SaveFormat.Pptx);
}
```
