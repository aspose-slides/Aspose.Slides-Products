Wie konvertiere ich PDF in HTML im Code?

Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) kann jeder Entwickler oder jede Anwendung PDF-Dateien mit nur wenigen Zeilen C#-Code in HTML-Dateien konvertieren.

Als moderne Dokumentenverarbeitungs-API exportiert Aspose.Slides für .NET PDF-Seiten schnell in HTML. Mit der Aspose PowerPoint-Bibliothek können Sie PDF in HTML und viele andere Dateiformate konvertieren.

So installieren Sie Aspose.Slides: Öffnen Sie den Paket-Manager [NuGet](https://www.nuget.org/packages/aspose.slides.net). Suchen Sie nach *Aspose.Slides* und installieren Sie es.
 
Oder Sie können **Aspose.Slides** installieren, indem Sie diesen Befehl über die Paket-Manager-Konsole ausführen.

```cs
using (Presentation pres = new Presentation())
    {
        pres.Slides.AddFromPdf("doc.pdf");
        pres.Slides.RemoveAt(0); // removes default empty slide
        pres.Save("doc.html", SaveFormat.Html);
    }
```
