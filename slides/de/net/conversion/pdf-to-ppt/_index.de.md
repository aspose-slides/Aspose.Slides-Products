Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) können Sie mit nur wenigen Codezeilen eine PDF- in eine PowerPoint-Präsentation konvertieren:

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-Code zum Konvertieren von PDF in PPT" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromPdf("InputPDF.pdf");
    pres.Save("OutputPresentation.ppt", SaveFormat.Ppt);
}
```
