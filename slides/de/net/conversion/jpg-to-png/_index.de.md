Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) kann jeder Entwickler oder jede Anwendung JPG mit nur wenigen Zeilen C#-Code in PNG konvertieren.

```cs
using (Presentation pres = new Presentation())
    {
        IPPImage image = pres.Images.AddImage(File.ReadAllBytes("image.jpg"));
        pres.Slides[0].Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, image);

        pres.Slides[0].GetThumbnail(new Size(960, 720)).Save($"image.png", ImageFormat.png);
    }
```
