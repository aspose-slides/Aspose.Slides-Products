Wie konvertiere ich HTML programmgesteuert in PDF?

Mit [**Aspose.Slides for .NET**](https://products.aspose.com/slides/de/net/) kann jeder Entwickler oder jede Anwendung HTML mit nur wenigen Zeilen C#-Code in das PDF-Format konvertieren.

Als moderne Dokumentenverarbeitungs-API erstellt Aspose.Slides für .NET schnell PDFs aus HTML-Seiten. Mit der Aspose PowerPoint-Bibliothek können Sie HTML in PDF und viele andere Dateiformate konvertieren

So installieren Sie Aspose.Slides: Öffnen Sie den Paket-Manager [NuGet](https://www.nuget.org/packages/aspose.slides.net). Suchen Sie nach *Aspose.Slides* und installieren Sie es.
 
Oder Sie können **Aspose.Slides** installieren, indem Sie diesen Befehl über die Paket-Manager-Konsole ausführen.

{{< blocks/products/pf/slides-design-update-10-2026/code title="C#-Code zum Konvertieren von HTML in PDF" >}}
```cs
using (Presentation pres = new Presentation())
{
    pres.Slides.AddFromHtml("page.html");
    pres.Slides.RemoveAt(0); // remove default empty slide

    pres.Save("doc.pdf", SaveFormat.Pdf);
}
```
