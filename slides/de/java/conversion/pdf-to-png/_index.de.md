{{% blocks/products/pf/slides-design-update-10-2026/section h2="Konvertieren Sie PDF in PNG mit Java" variant="code" %}}

Um das PDF in PNG zu konvertieren, müssen Sie eine Präsentation aus der PDF-Datei erstellen und sie als PNG speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Java-Code zum Konvertieren von PDF in PNG" >}}
```java

Presentation pres = new Presentation();
try {
    pres.getSlides().addFromPdf("InputPDF.pdf");
    Dimension size = new Dimension(960, 720);
    for (int index = 0; index < pres.getSlides().size(); index++)
    {
        ISlide slide = pres.getSlides().get_Item(index);
        BufferedImage bufferedImage = slide.getThumbnail(size);
        ImageIO.write(bufferedImage, "PNG", new File("image_java_" + index + ".png"));
    }
} finally {
    if (pres != null) pres.dispose();
}
```
