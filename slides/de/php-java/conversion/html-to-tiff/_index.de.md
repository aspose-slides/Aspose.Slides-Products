Um das HTML in TIFF zu konvertieren, müssen Sie eine Präsentation aus der HTML-Datei erstellen und sie als TIFF speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="PHP-Code zum Konvertieren von HTML in TIFF" >}}
```php

<?php
require_once("http://localhost:8080/JavaBridge/java/Java.inc");
require_once("lib/aspose.slides.php");
        
$pres = new Presentation();
try
{
    $pres->getSlides()->removeAt(0);
    
    $filename = 'file.html';
    $f = fopen($filename, 'r');
    if ($f) {
        $contents = fread($f, filesize($filename));
        fclose($f);
    }
    
    $pres->getSlides()->addFromHtml($contents);        
    $pres->save("output.tiff", SaveFormat::Tiff);        
}
finally
{
    if ($pres != null) $pres->dispose();
}
?>
```
