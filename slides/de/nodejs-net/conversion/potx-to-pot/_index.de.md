Um das POTX in POT zu konvertieren, müssen Sie eine Präsentation aus der POTX-Datei erstellen und diese als POT speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-Code zum Konvertieren von POTX in POT" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.potx");
try
{
    pres.save("output.pot", SaveFormat.Pot);
}
finally
{
    if (pres != null) pres.dispose();
}
```
