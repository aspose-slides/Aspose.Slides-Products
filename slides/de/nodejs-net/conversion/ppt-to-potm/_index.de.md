Um das PPT in POTM zu konvertieren, müssen Sie eine Präsentation aus der PPT-Datei erstellen und diese als POTM speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-Code zum Konvertieren von PPT in POTM" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.ppt");
try
{
    pres.save("output.potm", SaveFormat.Potm);
}
finally
{
    if (pres != null) pres.dispose();
}
```
