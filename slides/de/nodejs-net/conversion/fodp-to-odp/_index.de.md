Um das FODP in ODP zu konvertieren, müssen Sie eine Präsentation aus der FODP-Datei erstellen und diese als ODP speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript-Code zum Konvertieren von FODP in ODP" >}}
```javascript

const fs = require('fs');
const asposeSlides = require('aspose.slides.via.net');
const { Presentation, SaveFormat } = asposeSlides;
var pres = new Presentation("welcome-to-powerpoint.fodp");
try
{
    pres.save("output.odp", SaveFormat.Odp);
}
finally
{
    if (pres != null) pres.dispose();
}
```
