Um das HTML in TIFF zu konvertieren, müssen Sie eine Präsentation aus der HTML-Datei erstellen und sie als TIFF speichern.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Code zum Konvertieren von HTML in TIFF" >}}
```python

import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("file.html", "rt", encoding="utf-8") as stream:
        data = stream.read()
    pres.slides.add_from_html(data)
    pres.save("doc.tiff", slides.export.SaveFormat.TIFF)

```
