Mit [**Aspose.Slides for Python via .NET**](https://products.aspose.com/slides/de/python-net/) können Sie mit nur wenigen Codezeilen ein JPG-Bild in eine PowerPoint-Präsentation konvertieren:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Code zum Konvertieren von JPG in PPT" >}}
```py
import aspose.slides as slides

with slides.Presentation() as pres:
    slide = pres.slides[0]
    with open("img.jpg", "rb") as in_file:
        image = pres.images.add_image(in_file)
        slide.shapes.add_picture_frame(slides.ShapeType.RECTANGLE, 0, 0, 720, 540, image)
    
    pres.save("pres_with_image.ppt", slides.export.SaveFormat.PPT)
```
