Mit [**Aspose.Slides for Python via .NET**](https://products.aspose.com/slides/de/python-net/) können Sie mit nur wenigen Codezeilen ein HTML-Dokument in eine PowerPoint-Präsentation konvertieren:

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python-Code zum Konvertieren von HTML in PPTX" >}}
```py
import aspose.slides as slides

with slides.Presentation() as pres:
    pres.slides.remove_at(0)
    with open("page.html", "rb") as htmlStream:
        pres.slides.add_from_html(htmlStream)

    pres.save("MyPresentation.pptx", slides.export.SaveFormat.PPTX)
```
