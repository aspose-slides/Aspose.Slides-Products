{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert HTML to XML in C#" %}}

Use [Aspose.Slides for .NET](/slides/net/) to import HTML content into presentation slides and save the resulting presentation in PowerPoint XML Presentation format. The generated XML represents a presentation; it is not a generic XML transformation of the source HTML markup. Install the package from [NuGet](https://www.nuget.org/packages/Aspose.Slides.NET/) or use the following Package Manager Console command.

{{< blocks/products/pf/slides-design-update-10-2026/code title="C# code to convert HTML to a PowerPoint XML Presentation" >}}
```cs
using var presentation = new Presentation();

var htmlContent = File.ReadAllText("page.html");
presentation.Slides.AddFromHtml(htmlContent);
presentation.Slides.RemoveAt(0);

presentation.Save("document.xml", SaveFormat.Xml);
```
