{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PDF to XML in C#" %}}

Use [Aspose.Slides for .NET](/slides/net/) to import PDF pages into presentation slides and save the resulting presentation in PowerPoint XML Presentation format. The output describes the imported presentation; it is not a generic XML representation of the source PDF. Install the package from [NuGet](https://www.nuget.org/packages/Aspose.Slides.NET/) or use the following Package Manager Console command.

```powershell
PM> Install-Package Aspose.Slides.NET
```

{{< blocks/products/pf/slides-design-update-10-2026/code title="C# code to convert PDF to a PowerPoint XML Presentation" >}}
```cs
using var presentation = new Presentation();
presentation.Slides.AddFromPdf("document.pdf");
presentation.Slides.RemoveAt(0);
presentation.Save("document.xml", SaveFormat.Xml);
```
