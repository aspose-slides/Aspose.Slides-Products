{{% blocks/products/pf/agp/code-block title="C# code to convert PDF to JPG" offSpacer="" %}}

```cs
using var presentation = new Presentation();
presentation.Slides.AddFromPdf("document.pdf");
presentation.Slides.RemoveAt(0);

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(new Size(960, 720));
    image.Save($"Slide_{slide.SlideNumber}.jpg", ImageFormat.Jpeg);
}
```
