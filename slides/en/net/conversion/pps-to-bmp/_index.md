{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPS to BMP C# Conversion" >}}
```cs
using var presentation = new Presentation("template.pps");

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(1f, 1f);
    image.Save($"Slide_{slide.SlideNumber}.bmp", ImageFormat.Bmp);
}
```
