{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPS to SVG C# conversion" >}}
```cs
using var presentation = new Presentation("template.pps");

for (var slideIndex = 0; slideIndex < presentation.Slides.Count; slideIndex++)
{
    var slide = presentation.Slides[slideIndex];
    using var fileStream = File.Create($"slide-{slideIndex + 1}.svg");
    slide.WriteAsSvg(fileStream);
}
```
