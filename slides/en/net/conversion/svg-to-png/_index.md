{{% blocks/products/pf/agp/code-block title="This sample code shows SVG to PNG C# conversion" offSpacer="" %}}

```cs
using var presentation = new Presentation();
var svgImage = new SvgImage("source.svg");
var presentationImage = presentation.Images.AddImage(svgImage);
var slide = presentation.Slides[0];
slide.Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, presentationImage);

using var image = slide.GetImage(1f, 1f);
image.Save("image.png", ImageFormat.Png);
```
