{{< blocks/products/pf/slides-design-update-10-2026/code title="C# code to convert PDF to HTML" >}}
```cs
using var presentation = new Presentation();
presentation.Slides.AddFromPdf("document.pdf");
presentation.Slides.RemoveAt(0);
presentation.Save("document.html", SaveFormat.Html);
```
