{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPSM to PNG C# conversion" >}}
```cs
using var presentation = new Presentation("template.ppsm");

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(1f, 1f);
    image.Save($"Slide_{slide.SlideNumber}.png", ImageFormat.Png);
}
```
