{{% blocks/products/pf/agp/code-block title="This sample code shows POTX to JPEG C# Conversion" offSpacer="" %}}

```cs
using var presentation = new Presentation("template.potx");

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(1f, 1f);
    image.Save($"Slide_{slide.SlideNumber}.jpeg", ImageFormat.Jpeg);
}
```
