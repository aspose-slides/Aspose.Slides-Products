{{% blocks/products/pf/agp/code-block title="This sample code shows OTP to BMP C# Conversion" offSpacer="" %}}

```cs
using var presentation = new Presentation("template.otp");

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(1f, 1f);
    image.Save($"Slide_{slide.SlideNumber}.bmp", ImageFormat.Bmp);
}
```
