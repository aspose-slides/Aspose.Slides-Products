{{% blocks/products/pf/agp/code-block title="This sample code shows PPSM to JPEG C# conversion" offSpacer="" %}}

```cs
using var presentation = new Presentation("template.ppsm");

foreach (var slide in presentation.Slides)
{
    using var image = slide.GetImage(1f, 1f);
    image.Save($"Slide_{slide.SlideNumber}.jpeg", ImageFormat.Jpeg);
}
```
