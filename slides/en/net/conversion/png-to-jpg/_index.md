{{% blocks/products/pf/agp/code-block title="C# code to convert PNG to JPG" offSpacer="" %}}

```cs
using var presentation = new Presentation();
var slide = presentation.Slides[0];

var imageData = File.ReadAllBytes("image.png");
var presentationImage = presentation.Images.AddImage(imageData);
slide.Shapes.AddPictureFrame(ShapeType.Rectangle, 0, 0, 720, 540, presentationImage);

using var renderedImage = slide.GetImage(new Size(960, 720));
renderedImage.Save("image.jpg", ImageFormat.Jpeg);
```
