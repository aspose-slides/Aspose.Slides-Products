{{% blocks/products/pf/agp/code-block title="Python code for merging PPT files into a single XPS document" offSpacer="true" %}}

```python
with slides.Presentation("destination.ppt") as destination_presentation:
    with slides.Presentation("source.ppt") as source_presentation:
        for slide in source_presentation.slides:
            destination_presentation.slides.add_clone(slide)

    destination_presentation.save("merged-presentation.xps", slides.export.SaveFormat.XPS)
```
