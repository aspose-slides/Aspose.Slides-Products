{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPS to PPTX in Python" %}}

[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert PPS slide shows to PPTX presentations programmatically. Load the source file into a `Presentation` instance and export it by using `Presentation.save` with `SaveFormat.PPTX`.

PPTX is the modern PowerPoint Open XML presentation format and is suitable for editing and sharing. Microsoft PowerPoint is not required. You can also test the conversion in your [browser](https://products.aspose.app/slides/conversion).

Install the library from [PyPI](https://pypi.org/project/aspose-slides/) by using the following command:


```python
with slides.Presentation("presentation.pps") as presentation:
    presentation.save("presentation.pptx", slides.export.SaveFormat.PPTX)
```
