[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert POTX presentation templates to PPS slide shows programmatically. Load the POTX file into a `Presentation` instance and call `Presentation.save` with `SaveFormat.PPS`.

Install the library from [PyPI](https://pypi.org/project/aspose-slides/) by using the following command:
