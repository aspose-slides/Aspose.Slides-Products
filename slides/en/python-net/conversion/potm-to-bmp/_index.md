[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert POTM macro-enabled presentation templates to BMP images programmatically. Load the template, render each slide with `Slide.get_image`, and save the resulting `IImage` object in BMP format.

The API preserves slide content and formatting during rendering. You can test the conversion in your [browser](https://products.aspose.app/slides/conversion) or use the Python API to process templates in your application.

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows how to convert POTM to BMP in Python" >}}
```python
image_scale = 2

with slides.Presentation("presentation.potm") as presentation:
    for slide in presentation.slides:
        file_path = f"presentation_slide_{slide.slide_number}.bmp"
        with slide.get_image(image_scale, image_scale) as slide_image:
            slide_image.save(file_path, slides.ImageFormat.BMP)
```
