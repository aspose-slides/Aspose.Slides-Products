{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPS to POTM in Python" %}}

[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert a PowerPoint Slide Show in PPS format to a PowerPoint Macro-Enabled Template in POTM format. Load the PPS file into a `Presentation` instance and save it by using `SaveFormat.POTM`.

The API preserves presentation content and formatting during conversion and does not require Microsoft PowerPoint. Test the conversion in the free [online app](https://products.aspose.app/slides/conversion) or integrate the Python API into your application.

Install the library from [PyPI](https://pypi.org/project/aspose-slides/) by using the following command:

```python
with slides.Presentation("presentation.pps") as presentation:
    presentation.save("presentation.potm", slides.export.SaveFormat.POTM)
```
