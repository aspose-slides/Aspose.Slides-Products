{{% blocks/products/pf/agp/code-block title="This sample code shows how to convert PPTX to PNG in Python" offSpacer="" %}}

```python
image_scale = 2

with slides.Presentation("presentation.pptx") as presentation:
    for slide in presentation.slides:
        file_path = "presentation_slide_{}.png".format(slide.slide_number)
        with slide.get_image(image_scale, image_scale) as slide_image:
            slide_image.save(file_path, slides.ImageFormat.PNG)
```
