[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert POT presentation templates to PDF documents programmatically. Load the template and call `Presentation.save` with `SaveFormat.PDF`.

PDF output preserves the presentation's slide layout and visual content in a fixed-layout document. You can test the conversion in your [browser](https://products.aspose.app/slides/conversion) or use the Python API in your application.

Install the library from [PyPI](https://pypi.org/project/aspose-slides/) by using the following command:

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows how to convert POT to PDF in Python" >}}
```python
with slides.Presentation("presentation.pot") as presentation:
    presentation.save("presentation.pdf", slides.export.SaveFormat.PDF)
```
