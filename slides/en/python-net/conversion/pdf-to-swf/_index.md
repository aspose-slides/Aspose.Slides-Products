[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert PDF files to SWF programmatically. The API imports each PDF page as a slide with `SlideCollection.add_from_pdf`, then exports the presentation with `Presentation.save` and `SaveFormat.SWF`.

SWF is a legacy Adobe Flash format intended for compatibility with older workflows and is not supported by modern web browsers. See the [presentation import guide](https://docs.aspose.com/slides/python-net/import-presentation/) for details about importing PDF pages.

Install the library from [PyPI](https://pypi.org/project/aspose-slides/) by using the following command:
