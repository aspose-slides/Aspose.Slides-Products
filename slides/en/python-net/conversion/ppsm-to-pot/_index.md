Convert PPSM files to POT programmatically with [*Aspose.Slides for Python via .NET*](/slides/python-net/). Load the source slide show and save it as a PowerPoint 97-2003 template with a few lines of Python code.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python example: Convert PPSM to POT" >}}
```python
with slides.Presentation("presentation.ppsm") as presentation:
    presentation.save("presentation.pot", slides.export.SaveFormat.POT)
```
