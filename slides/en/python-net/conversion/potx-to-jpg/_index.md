[*Aspose.Slides for Python via .NET*](/slides/python-net/) lets you convert POTX presentation templates to JPG images programmatically. Load the POTX file, render each slide with `Slide.get_image`, and save the resulting `IImage` object in JPEG format.

The API preserves slide content and formatting during rendering. You can test the conversion in your [browser](https://products.aspose.app/slides/conversion/potx-to-jpeg) or use the Python API in your application.

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows how to convert POTX to JPG in Python" >}}
```python
image_scale = 2

with slides.Presentation("presentation.potx") as presentation:
    for slide in presentation.slides:
        file_path = f"presentation_slide_{slide.slide_number}.jpg"
        with slide.get_image(image_scale, image_scale) as slide_image:
            slide_image.save(file_path, slides.ImageFormat.JPEG)
```
