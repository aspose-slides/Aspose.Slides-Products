{{% blocks/products/pf/agp/code-block title="This sample code shows how to convert ODP slides to SVG in Python" offSpacer="" %}}

```python
with slides.Presentation("presentation.odp") as presentation:
    for slide in presentation.slides:
        file_path = "presentation_slide_{}.svg".format(slide.slide_number)
        with open(file_path, "wb") as output_stream:
            slide.write_as_svg(output_stream)
```
