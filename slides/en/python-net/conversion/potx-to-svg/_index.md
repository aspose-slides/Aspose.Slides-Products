{{% blocks/products/pf/agp/code-block title="This sample code shows how to convert POTX slides to SVG in Python" offSpacer="" %}}

```python
with slides.Presentation("presentation.potx") as presentation:
    for slide in presentation.slides:
        file_path = f"presentation_slide_{slide.slide_number}.svg"
        with open(file_path, "wb") as output_stream:
            slide.write_as_svg(output_stream)
```
