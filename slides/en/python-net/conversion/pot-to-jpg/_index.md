{{% blocks/products/pf/agp/code-block title="This sample code shows how to convert POT to JPG in Python" offSpacer="" %}}

```python
with slides.Presentation("presentation.pot") as presentation:
    for slide_index, slide in enumerate(presentation.slides):
        file_path = f"slide_{slide_index + 1}.jpg"
        with slide.get_image() as slide_image:
            slide_image.save(file_path, slides.ImageFormat.JPEG)
```
