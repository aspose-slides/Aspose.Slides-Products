{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POT to PPSM using Node.js" variant="code" %}}

To convert `POT` to `PPSM`, create a `Presentation` from the source file and export it to a `PPSM` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert POT to PPSM" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.pot");
try {
    presentation.save("output.ppsm", aspose.slides.SaveFormat.Ppsm);
}
finally {
    presentation.dispose();
}
```
