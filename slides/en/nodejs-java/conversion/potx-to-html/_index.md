To convert `POTX` to `HTML`, create a `Presentation` from the source file and export it to an `HTML` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert POTX to HTML" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.potx");
try {
    presentation.save("output.html", aspose.slides.SaveFormat.Html);
}
finally {
    presentation.dispose();
}
```
