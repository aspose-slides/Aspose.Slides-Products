To convert `FODP` to `GIF`, create a `Presentation` from the source file and export it to a `GIF` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert FODP to GIF" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.fodp");
try {
    presentation.save("output.gif", aspose.slides.SaveFormat.Gif);
}
finally {
    presentation.dispose();
}
```
