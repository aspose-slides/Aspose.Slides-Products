To convert `OTP` to `FODP`, create a `Presentation` from the source file and export it to an `FODP` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert OTP to FODP" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.otp");
try {
    presentation.save("output.fodp", aspose.slides.SaveFormat.Fodp);
}
finally {
    presentation.dispose();
}
```
