{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSX to SVG using Node.js" variant="code" %}}

To convert `PPSX` to `SVG`, create a `Presentation` from the source file and export the required slide to an `SVG` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert PPSX to SVG" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.ppsx");
try {
    const slide = presentation.getSlides().get_Item(0);
    const svgStream = java.newInstanceSync("java.io.FileOutputStream", "slide.svg");
    try {
        slide.writeAsSvg(svgStream);
    }
    finally {
        svgStream.close();
    }
}
finally {
    presentation.dispose();
}
```
