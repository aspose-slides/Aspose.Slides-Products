To convert `OTP` to `POTM`, create a `Presentation` from the source file and export it to a `POTM` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert OTP to POTM" >}}
```javascript
const presentation = new aspose.slides.Presentation("sourceFile.otp");
try {
    presentation.save("output.potm", aspose.slides.SaveFormat.Potm);
}
finally {
    presentation.dispose();
}
```
