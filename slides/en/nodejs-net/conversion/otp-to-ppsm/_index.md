To convert `OTP` to `PPSM`, create a `Presentation` from the source file and export it to a `PPSM` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert OTP to PPSM" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.otp");
try {
    presentation.save("output.ppsm", asposeSlides.SaveFormat.Ppsm);
}
finally {
    presentation.dispose();
}
```
