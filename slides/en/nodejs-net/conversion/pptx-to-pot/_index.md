To convert `PPTX` to `POT`, create a `Presentation` from the source file and export it to a `POT` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript code to convert PPTX to POT" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.pptx");
try {
    presentation.save("output.pot", asposeSlides.SaveFormat.Pot);
}
finally {
    presentation.dispose();
}
```
