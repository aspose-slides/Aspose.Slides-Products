To convert `PPS` to `FODP`, create a `Presentation` from the source file and export it to an `FODP` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript code to convert PPS into FODP" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.pps");
try {
    presentation.save("output.fodp", asposeSlides.SaveFormat.Fodp);
}
finally {
    presentation.dispose();
}
```
