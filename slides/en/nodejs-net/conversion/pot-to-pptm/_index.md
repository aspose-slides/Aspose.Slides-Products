To convert `POT` to `PPTM`, create a `Presentation` from the source file and export it to a `PPTM` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert POT to PPTM" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.pot");
try {
    presentation.save("output.pptm", asposeSlides.SaveFormat.Pptm);
}
finally {
    presentation.dispose();
}
```
