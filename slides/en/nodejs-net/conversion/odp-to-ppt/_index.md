To convert `ODP` to `PPT`, create a `Presentation` from the source file and export it to a `PPT` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert ODP to PPT" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.odp");
try {
    presentation.save("output.ppt", asposeSlides.SaveFormat.Ppt);
}
finally {
    presentation.dispose();
}
```
