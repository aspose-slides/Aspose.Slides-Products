To convert `PPTM` to `GIF`, create a `Presentation` from the source file and export it to a `GIF` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="JavaScript code to convert PPTM to GIF" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.pptm");
try {
    presentation.save("output.gif", asposeSlides.SaveFormat.Gif);
}
finally {
    presentation.dispose();
}
```
