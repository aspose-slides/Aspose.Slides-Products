To convert `POT` to `OTP`, create a `Presentation` from the source file and export it to an `OTP` file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Node.js code to convert POT to OTP" >}}
```javascript
const presentation = new asposeSlides.Presentation("sourceFile.pot");
try {
    presentation.save("output.otp", asposeSlides.SaveFormat.Otp);
}
finally {
    presentation.dispose();
}
```
