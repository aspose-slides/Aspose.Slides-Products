{{% blocks/products/pf/agp/code-block title="POTM to GIF Java Conversion Source Code" offSpacer="" %}}

```java
Presentation presentation = new Presentation("template.potm");
try {
    for (ISlide slide : presentation.getSlides()) {
        IImage slideImage = slide.getImage(1f, 1f);
        try {
            slideImage.save("slide_" + slide.getSlideNumber() + ".gif", ImageFormat.Gif);
        } finally {
            slideImage.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```
