{{% blocks/products/pf/agp/code-block title="ODP to PNG Java Conversion Source Code" offSpacer="" %}}

```java
Presentation presentation = new Presentation("template.odp");
try {
    for (ISlide slide : presentation.getSlides()) {
        IImage slideImage = slide.getImage(1f, 1f);
        try {
            slideImage.save("slide_" + slide.getSlideNumber() + ".png", ImageFormat.Png);
        } finally {
            slideImage.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```
