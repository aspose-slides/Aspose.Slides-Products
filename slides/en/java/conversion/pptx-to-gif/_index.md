{{% blocks/products/pf/agp/code-block title="PPTX to GIF Java Conversion Source Code" offSpacer="" %}}

```java
Presentation presentation = new Presentation("presentation.pptx");
try {
    for (ISlide slide : presentation.getSlides()) {
        IImage slideImage = slide.getImage(1f, 1f);
        try {
            slideImage.save("slide_" + slide.getSlideNumber() + ".gif", ImageFormat.Gif);
        } finally {
            slideImage.dispose();
        }
    }
} finally {
    presentation.dispose();
}
```
