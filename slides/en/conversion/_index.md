{{< blocks/products/pf/agp/faq-item question="Does converting a presentation to PDF require Microsoft PowerPoint?" answer="No. The presentation is rendered directly by the library, which is what makes conversion usable on a server or inside a container." >}}
{{< blocks/products/pf/agp/faq-item question="Which conversions are available?" answer="PPT, PPTX, POTX, POTM and ODP convert between one another, and to PDF and HTML. The exact set of export targets varies by platform — the platform pages list theirs." >}}
{{< blocks/products/pf/agp/faq-item question="Will fonts look the same after conversion?" answer="Only if the fonts are available to the process doing the conversion. A server with a minimal font set will substitute, and the layout will shift. Install or embed the fonts the deck uses." >}}
{{< blocks/products/pf/agp/faq-item question="Can I convert a single slide rather than the whole deck?" answer="Yes. Slides can be rendered individually, which is how per-slide thumbnails and previews are produced without exporting the entire presentation." >}}
