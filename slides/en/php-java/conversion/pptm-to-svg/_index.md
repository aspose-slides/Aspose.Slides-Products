{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPTM to SVG PHP Conversion" >}}
```php
$presentation = new Presentation("input.pptm");
try {
    $slideCount = java_values($presentation->getSlides()->size());

    for ($slideIndex = 0; $slideIndex < $slideCount; $slideIndex++) {
        $slide = $presentation->getSlides()->get_Item($slideIndex);
        $filePath = "slide_" . ($slideIndex + 1) . ".svg";
        $fileStream = new Java("java.io.FileOutputStream", $filePath);

        try {
            $slide->writeAsSvg($fileStream);
        } finally {
            $fileStream->close();
        }
    }
} finally {
    $presentation->dispose();
}
```
