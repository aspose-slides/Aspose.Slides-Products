{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPSX to FODP PHP Conversion" >}}
```php
$presentation = new Presentation("input.ppsx");
try {
    $presentation->save("output.fodp", SaveFormat::Fodp);
} finally {
    $presentation->dispose();
}
```
