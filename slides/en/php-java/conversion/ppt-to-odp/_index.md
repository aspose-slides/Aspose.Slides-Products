Convert PPT files to ODP programmatically with [*Aspose.Slides for PHP via Java*](/slides/php-java/). Load a PowerPoint 97-2003 presentation and save it as an OpenDocument Presentation with a few lines of PHP code.

Aspose.Slides performs the conversion through the `Presentation` class and its `save` method. You can also try the PPT-to-ODP conversion in your [browser](https://products.aspose.app/slides/conversion) before integrating it into your application.

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPT-to-ODP conversion in PHP" >}}
```php
$presentation = new Presentation("input.ppt");
try {
    $presentation->save("output.odp", SaveFormat::Odp);
} finally {
    $presentation->dispose();
}
```
