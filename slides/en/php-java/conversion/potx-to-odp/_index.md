[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a PowerPoint POTX template and save it as an OpenDocument Presentation without Microsoft PowerPoint.

Call `save` with `SaveFormat::Odp` to create the ODP file while preserving the presentation's slides and supported content.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

```php
$presentation = new Presentation("input.potx");
try {
    $presentation->save("output.odp", SaveFormat::Odp);
} finally {
    $presentation->dispose();
}
```
