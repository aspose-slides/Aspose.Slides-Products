[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a PowerPoint POTX template and save it as a Flat OpenDocument Presentation without Microsoft PowerPoint.

Call `save` with `SaveFormat::Fodp` to create a single XML-based FODP file containing the presentation. The original POTX file is not modified.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:
