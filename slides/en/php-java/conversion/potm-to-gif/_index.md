[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a macro-enabled PowerPoint POTM template and render its slides as an animated GIF without Microsoft PowerPoint.

Call `save` with `SaveFormat::Gif` to create the animation using the default frame size, slide delay, and transition settings. The GIF contains rendered slide frames and does not retain the VBA project from the source template.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

```php
$presentation = new Presentation("input.potm");
try {
    $presentation->save("output.gif", SaveFormat::Gif);
} finally {
    $presentation->dispose();
}
```
