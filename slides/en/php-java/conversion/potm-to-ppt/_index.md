{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTM to PPT in PHP" %}}

[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a macro-enabled PowerPoint POTM template and save it as a PowerPoint 97-2003 PPT presentation without Microsoft PowerPoint.

Call `save` with `SaveFormat::Ppt` to create an editable binary presentation rather than a reusable template. Features introduced in newer PowerPoint versions may be represented differently in the legacy output format.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

```php
$presentation = new Presentation("input.potm");
try {
    $presentation->save("output.ppt", SaveFormat::Ppt);
} finally {
    $presentation->dispose();
}
```
