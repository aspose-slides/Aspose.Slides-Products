Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to load a PowerPoint 97–2003 POT template and save it as a PowerPoint Open XML PPSX slide show.

Call `save` with `SaveFormat::Ppsx` to create the slide show. PPSX is a macro-free format, so use PPSM when the output must support VBA projects.
