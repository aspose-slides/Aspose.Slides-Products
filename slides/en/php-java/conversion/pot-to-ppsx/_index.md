Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to load a PowerPoint 97–2003 POT template and save it as a PowerPoint Open XML PPSX slide show.

Call `save` with `SaveFormat::Ppsx` to create the slide show. PPSX is a macro-free format, so use PPSM when the output must support VBA projects.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows POT to PPSX PHP Conversion" >}}
```php
$presentation = new Presentation("input.pot");
try {
    $presentation->save("output.ppsx", SaveFormat::Ppsx);
} finally {
    $presentation->dispose();
}
```
