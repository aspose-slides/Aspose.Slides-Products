[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a PowerPoint PPS slide show and save it as a Flat OpenDocument Presentation without Microsoft PowerPoint.

Call `save` with `SaveFormat::Fodp` to create a single XML-based FODP file containing the presentation. VBA projects from the source file are not retained in the FODP output.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:
