Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to import the pages of a PDF document as slides and save the result as a PowerPoint 97-2003 slide show (PPS).

Call `addFromPdf` to import the PDF pages, then call `save` with `SaveFormat::Pps` to create the slide show. You can also test PDF conversion in your [browser](https://products.aspose.app/slides/conversion).

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{% blocks/products/pf/agp/code-block title="This sample code shows PDF to PPS PHP Conversion" offSpacer="" %}}

```php
$presentation = new Presentation();
try {
    $presentation->getSlides()->removeAt(0);
    $presentation->getSlides()->addFromPdf("document.pdf");
    $presentation->save("output.pps", SaveFormat::Pps);
} finally {
    $presentation->dispose();
}
```
