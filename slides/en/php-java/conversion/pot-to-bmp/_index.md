Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to load a PowerPoint 97–2003 POT template and render each slide as a separate BMP image.

Call `getImage` for each slide and save the rendered image with `ImageFormat::Bmp`. A scale factor of `2.0` produces an image at twice the slide's default rendering dimensions.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows POT to BMP PHP Conversion" >}}
```php
$presentation = new Presentation("input.pot");
try {
    $slideCount = java_values($presentation->getSlides()->size());

    for ($slideIndex = 0; $slideIndex < $slideCount; $slideIndex++) {
        $slide = $presentation->getSlides()->get_Item($slideIndex);
        $slideImage = $slide->getImage(2.0, 2.0);

        try {
            $filePath = "slide_" . ($slideIndex + 1) . ".bmp";
            $slideImage->save($filePath, ImageFormat::Bmp);
        } finally {
            $slideImage->dispose();
        }
    }
} finally {
    $presentation->dispose();
}
```
