{{% blocks/products/pf/agp/content h2="Convert POTM to XPS in PHP" %}}

[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a macro-enabled PowerPoint POTM template and export it as a fixed-layout XPS document without Microsoft PowerPoint.

Call `save` with `SaveFormat::Xps` to create the output file. The XPS document contains rendered presentation content and does not retain the VBA project from the source template.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

