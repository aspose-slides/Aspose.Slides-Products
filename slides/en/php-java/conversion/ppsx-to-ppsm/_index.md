Convert PPSX files to PPSM programmatically with [*Aspose.Slides for PHP via Java*](/slides/php-java/). Load a PowerPoint Open XML Slide Show and save it in the macro-enabled Open XML slide show format with a few lines of PHP code.

Aspose.Slides performs the conversion through the `Presentation` class and its `save` method. You can also try the PPSX-to-PPSM conversion in your [browser](https://products.aspose.app/slides/conversion) before integrating it into your application.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPSX-to-PPSM conversion in PHP" >}}
```php
$presentation = new Presentation("input.ppsx");
try {
    $presentation->save("output.ppsm", SaveFormat::Ppsm);
} finally {
    $presentation->dispose();
}
```
