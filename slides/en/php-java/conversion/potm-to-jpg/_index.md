[*Aspose.Slides for PHP via Java*](/slides/php-java/) can load a macro-enabled PowerPoint POTM template and render each slide as a JPG image without Microsoft PowerPoint.

Call `getImage` for each slide and save the rendered image with `ImageFormat::Jpeg`. A scale factor of `2.0` produces an image at twice the slide's default rendering dimensions. JPG files contain rendered slide content and do not retain the VBA project from the source template.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{% blocks/products/pf/agp/code-block title="This sample code shows POTM to JPG PHP Conversion" offSpacer="" %}}

```php
$presentation = new Presentation("input.potm");
try {
    $slideCount = java_values($presentation->getSlides()->size());

    for ($slideIndex = 0; $slideIndex < $slideCount; $slideIndex++) {
        $slide = $presentation->getSlides()->get_Item($slideIndex);
        $slideImage = $slide->getImage(2.0, 2.0);

        try {
            $filePath = "slide_" . ($slideIndex + 1) . ".jpg";
            $slideImage->save($filePath, ImageFormat::Jpeg);
        } finally {
            $slideImage->dispose();
        }
    }
} finally {
    $presentation->dispose();
}
```
