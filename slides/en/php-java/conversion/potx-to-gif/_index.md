Call `save` with `SaveFormat::Gif` to create the animation using the default frame size, slide delay, and transition settings.

```php
$presentation = new Presentation("input.potx");
try {
    $presentation->save("output.gif", SaveFormat::Gif);
} finally {
    $presentation->dispose();
}
```
