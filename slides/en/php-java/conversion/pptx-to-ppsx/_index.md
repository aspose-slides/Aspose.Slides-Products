Convert PPTX files to PPSX programmatically with [*Aspose.Slides for PHP via Java*](/slides/php-java/). Load an Open XML PowerPoint presentation and save it as an Open XML PowerPoint slide show with a few lines of PHP code.

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPTX-to-PPSX conversion in PHP" >}}
```php
$presentation = new Presentation("input.pptx");
try {
    $presentation->save("output.ppsx", SaveFormat::Ppsx);
} finally {
    $presentation->dispose();
}
```
