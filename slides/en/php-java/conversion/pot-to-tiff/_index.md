{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POT to TIFF in PHP" %}}

Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to load a PowerPoint 97–2003 POT template and render all slides into one multipage TIFF image.

Call `save` with `SaveFormat::Tiff`; each slide becomes a page in the TIFF output.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows POT to TIFF PHP Conversion" >}}
```php
$presentation = new Presentation("input.pot");
try {
    $presentation->save("output.tiff", SaveFormat::Tiff);
} finally {
    $presentation->dispose();
}
```
