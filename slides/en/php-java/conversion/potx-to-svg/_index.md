Call `writeAsSvg` for each slide and write the result to a separate output stream. Each SVG file contains the rendered content of one slide.

{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows POTX to SVG PHP Conversion" >}}
```php
$presentation = new Presentation("input.potx");
try {
    $slideCount = java_values($presentation->getSlides()->size());

    for ($slideIndex = 0; $slideIndex < $slideCount; $slideIndex++) {
        $slide = $presentation->getSlides()->get_Item($slideIndex);
        $filePath = "slide_" . ($slideIndex + 1) . ".svg";
        $outputStream = new Java("java.io.FileOutputStream", $filePath);

        try {
            $slide->writeAsSvg($outputStream);
        } finally {
            $outputStream->close();
        }
    }
} finally {
    $presentation->dispose();
}
```
