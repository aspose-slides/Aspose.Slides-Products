Use [*Aspose.Slides for PHP via Java*](/slides/php-java/) to load a PowerPoint 97–2003 POT template and save it as a macro-enabled PowerPoint PPSM slide show.

Call `save` with `SaveFormat::Ppsm` to create the PPSM file. The format can store VBA projects, but conversion does not add macros that are not present in the source.

You can install the library from [Composer](https://packagist.org/packages/aspose/slides) using the following command:
