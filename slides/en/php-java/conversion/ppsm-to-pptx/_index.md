{{< blocks/products/pf/slides-design-update-10-2026/code title="This sample code shows PPSM to PPTX PHP Conversion" >}}
```php
$presentation = new Presentation("input.ppsm");
try {
    $presentation->save("output.pptx", SaveFormat::Pptx);
} finally {
    $presentation->dispose();
}
```
