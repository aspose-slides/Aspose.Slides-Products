[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a macro-enabled POTM file and save it as a PPSM slide show. {{% blocks/products/pf/feature-page-section  h2="Convert POTM to PPSM using Python" %}}
Create a `Presentation` from the POTM file, then call `save` with `SaveFormat.Ppsm`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POTM to PPSM" offSpacer="true" %}}

```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.ppsm", SaveFormat.Ppsm)
finally:
    presentation.dispose()
```
