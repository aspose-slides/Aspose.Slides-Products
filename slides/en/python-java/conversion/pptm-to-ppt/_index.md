{{% blocks/products/pf/feature-page-section  h2="Convert PPTM to PPT using Python" %}}
Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Ppt`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTM to PPT" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
