{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to PPT using Python" variant="code" %}}

Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Ppt`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to PPT" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
