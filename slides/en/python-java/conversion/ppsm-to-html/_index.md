{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSM to HTML using Python" variant="code" %}}

Create a `Presentation` from the PPSM file and call `save` with `SaveFormat.Html` to generate an HTML document.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSM to HTML" >}}
```python
presentation = Presentation("presentation.ppsm")
try:
    presentation.save("presentation.html", SaveFormat.Html)
finally:
    presentation.dispose()
```
