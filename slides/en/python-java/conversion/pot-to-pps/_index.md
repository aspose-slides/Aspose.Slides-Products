{{% blocks/products/pf/feature-page-section  h2="Convert POT to PPS using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Pps`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to PPS" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.pps", SaveFormat.Pps)
finally:
    presentation.dispose()
```
