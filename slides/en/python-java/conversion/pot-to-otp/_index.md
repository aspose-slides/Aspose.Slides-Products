{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POT to OTP using Python" variant="code" %}}

Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Otp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POT to OTP" >}}
```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
