[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a POT file and export it as an OpenDocument Presentation Template (OTP). The output remains a reusable presentation template and does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.

{{% blocks/products/pf/feature-page-section  h2="Convert POT to OTP using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Otp`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to OTP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
