{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to PPSX using Python" variant="code" %}}

Create a `Presentation` from the PPTX file, then call `save` with `SaveFormat.Ppsx`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to PPSX" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.ppsx", SaveFormat.Ppsx)
finally:
    presentation.dispose()
```
