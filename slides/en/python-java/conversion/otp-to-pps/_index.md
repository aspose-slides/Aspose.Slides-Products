[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an OTP presentation template and save it as a PowerPoint 97-2003 PPS slide show. {{% blocks/products/pf/feature-page-section  h2="Convert OTP to PPS using Python" %}}
Create a `Presentation` from the OTP file and call `save` with `SaveFormat.Pps` to create the PPS slide show.

{{% blocks/products/pf/agp/code-block title="Python code for converting OTP to PPS" offSpacer="true" %}}

```python
presentation = Presentation("presentation.otp")
try:
    presentation.save("presentation.pps", SaveFormat.Pps)
finally:
    presentation.dispose()
```
