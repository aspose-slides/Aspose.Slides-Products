{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to GIF using Python" variant="code" %}}

Create a `Presentation` from the source PPTX file, then call `save` with `SaveFormat.Gif` to generate an animated GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to animated GIF" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
