{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to OTP using Python" variant="code" %}}

Create a `Presentation` from the PPTX file and call `save` with `SaveFormat.Otp` to generate the OTP presentation template.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to OTP" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
