{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPT to PPTM using Python" variant="code" %}}

Create a `Presentation` from the source PPT file, then call `save` with `SaveFormat.Pptm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPT to PPTM" >}}
```python
presentation = Presentation("presentation.ppt")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
