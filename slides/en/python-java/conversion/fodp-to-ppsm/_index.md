{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to PPSM using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Ppsm` to create the PPSM slide show.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to PPSM" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.ppsm", SaveFormat.Ppsm)
finally:
    presentation.dispose()
```
