{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPT to FODP using Python" variant="code" %}}

Create a `Presentation` from the source PPT file, then call `save` with `SaveFormat.Fodp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPT to FODP" >}}
```python
presentation = Presentation("presentation.ppt")
try:
    presentation.save("presentation.fodp", SaveFormat.Fodp)
finally:
    presentation.dispose()
```
