{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPS to PPTM using Python" variant="code" %}}

Create a `Presentation` from the PPS file, then call `save` with `SaveFormat.Pptm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPS to PPTM" >}}
```python
presentation = Presentation("presentation.pps")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
