{{% blocks/products/pf/feature-page-section  h2="Convert PPSM to PPT using Python" %}}
Create a `Presentation` from the PPSM file and call `save` with `SaveFormat.Ppt` to create the PPT file.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPSM to PPT" offSpacer="true" %}}

```python
presentation = Presentation("presentation.ppsm")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
