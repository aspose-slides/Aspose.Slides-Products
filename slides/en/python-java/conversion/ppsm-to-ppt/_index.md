{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSM to PPT using Python" variant="code" %}}

Create a `Presentation` from the PPSM file and call `save` with `SaveFormat.Ppt` to create the PPT file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSM to PPT" >}}
```python
presentation = Presentation("presentation.ppsm")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
