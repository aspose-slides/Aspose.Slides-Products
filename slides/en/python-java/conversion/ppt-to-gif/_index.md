{{% blocks/products/pf/feature-page-section  h2="Convert PPT to GIF using Python" %}}
Create a `Presentation` from the source PPT file, then call `save` with `SaveFormat.Gif` to generate an animated GIF.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPT to animated GIF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.ppt")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
