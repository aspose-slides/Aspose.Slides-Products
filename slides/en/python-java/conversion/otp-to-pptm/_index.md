[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an OpenDocument Presentation Template (OTP) and save it in the macro-enabled PowerPoint PPTM format. PPTM supports VBA projects, but converting an OTP file does not add macros to the presentation. The conversion does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.

{{% blocks/products/pf/feature-page-section  h2="Convert OTP to PPTM using Python" %}}
Create a `Presentation` from the OTP file and call `save` with `SaveFormat.Pptm` to create the PPTM file.

{{% blocks/products/pf/agp/code-block title="Python code for converting OTP to PPTM" offSpacer="true" %}}

```python
presentation = Presentation("presentation.otp")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
