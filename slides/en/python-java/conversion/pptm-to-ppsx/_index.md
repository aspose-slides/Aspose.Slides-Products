{{% blocks/products/pf/feature-page-section  h2="Convert PPTM to PPSX using Python" %}}
Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Ppsx`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTM to PPSX" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.ppsx", SaveFormat.Ppsx)
finally:
    presentation.dispose()
```
