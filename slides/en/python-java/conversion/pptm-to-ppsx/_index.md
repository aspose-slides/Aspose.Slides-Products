{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to PPSX using Python" variant="code" %}}

Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Ppsx`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to PPSX" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.ppsx", SaveFormat.Ppsx)
finally:
    presentation.dispose()
```
