{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to POTX using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Potx` to create the POTX file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to POTX" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.potx", SaveFormat.Potx)
finally:
    presentation.dispose()
```
