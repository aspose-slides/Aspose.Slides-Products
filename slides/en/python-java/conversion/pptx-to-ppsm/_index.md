{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to PPSM using Python" variant="code" %}}

Create a `Presentation` from the PPTX file, then call `save` with `SaveFormat.Ppsm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to PPSM" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.ppsm", SaveFormat.Ppsm)
finally:
    presentation.dispose()
```
