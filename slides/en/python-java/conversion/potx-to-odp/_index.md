{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to ODP using Python" variant="code" %}}

Create a `Presentation` from the POTX file, then call `save` with `SaveFormat.Odp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to ODP" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
