{{% blocks/products/pf/feature-page-section  h2="Convert POTM to GIF using Python" %}}
Create a `Presentation` from the POTM file and call `save` with `SaveFormat.Gif` to create an animated GIF.

{{% blocks/products/pf/agp/code-block title="Python code for converting POTM to animated GIF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
