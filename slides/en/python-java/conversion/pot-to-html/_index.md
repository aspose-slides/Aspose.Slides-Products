Create a `Presentation` from the POT file and call `save` with `SaveFormat.Html` to generate an HTML document.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POT to HTML" >}}
```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.html", SaveFormat.Html)
finally:
    presentation.dispose()
```
