{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to ODP using Python" variant="code" %}}

Create a `Presentation` from the PPTX file and call `save` with `SaveFormat.Odp` to generate the ODP presentation.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to ODP" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
