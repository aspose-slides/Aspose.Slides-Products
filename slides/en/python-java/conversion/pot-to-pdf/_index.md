{{% blocks/products/pf/feature-page-section  h2="Convert POT to PDF using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Pdf`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to PDF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.pdf", SaveFormat.Pdf)
finally:
    presentation.dispose()
```
