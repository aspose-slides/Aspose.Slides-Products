{{% blocks/products/pf/feature-page-section  h2="Convert POT to PPTM using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Pptm`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to PPTM" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
