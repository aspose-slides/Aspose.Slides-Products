{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to PPSM using Python" variant="code" %}}

Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Ppsm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to PPSM" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.ppsm", SaveFormat.Ppsm)
finally:
    presentation.dispose()
```
