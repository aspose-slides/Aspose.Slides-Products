{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSX to PPTX using Python" variant="code" %}}

Create a `Presentation` from the PPSX file, then call `save` with `SaveFormat.Pptx`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSX to PPTX" >}}
```python
presentation = Presentation("presentation.ppsx")
try:
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```
