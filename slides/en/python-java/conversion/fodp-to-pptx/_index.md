{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to PPTX using Python" variant="code" %}}

Create a `Presentation` from the FODP file, then call `save` with `SaveFormat.Pptx`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to PPTX" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```
