{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to POTM using Python" variant="code" %}}

Create a `Presentation` from the source PPTM file, then call `save` with `SaveFormat.Potm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python tutorial for converting PPTM into POTM" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.potm", SaveFormat.Potm)
finally:
    presentation.dispose()
```
