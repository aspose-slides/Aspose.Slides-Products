[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a macro-enabled PowerPoint presentation (`.pptm`) and render its slides as pages in a single multipage TIFF (`.tiff`) image. {{% blocks/products/pf/feature-page-section  h2="Convert PPTM to TIFF using Python" %}}
Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Tiff`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTM to TIFF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.tiff", SaveFormat.Tiff)
finally:
    presentation.dispose()
```
