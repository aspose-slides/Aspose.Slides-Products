{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to TIFF using Python" variant="code" %}}

Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Tiff`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to TIFF" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.tiff", SaveFormat.Tiff)
finally:
    presentation.dispose()
```
