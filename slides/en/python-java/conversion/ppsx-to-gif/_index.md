{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSX to GIF using Python" variant="code" %}}

Create a `Presentation` from the PPSX file and call `save` with `SaveFormat.Gif` to create an animated GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSX to animated GIF" >}}
```python
presentation = Presentation("presentation.ppsx")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
