{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to OTP using Python" variant="code" %}}

Create a `Presentation` from the POTX file, then call `save` with `SaveFormat.Otp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to OTP" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
