{{% blocks/products/pf/feature-page-section  h2="Convert POTX to OTP using Python" %}}
Create a `Presentation` from the POTX file, then call `save` with `SaveFormat.Otp`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POTX to OTP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
