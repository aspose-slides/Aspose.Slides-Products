{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to POT using Python" variant="code" %}}

Create a `Presentation` from the PPTX file and call `save` with `SaveFormat.Pot` to create the POT file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to POT" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.pot", SaveFormat.Pot)
finally:
    presentation.dispose()
```
