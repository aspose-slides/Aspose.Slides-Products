{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTM to PPTM using Python" variant="code" %}}

Create a `Presentation` from the POTM file, then call `save` with `SaveFormat.Pptm`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTM to PPTM" >}}
```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```

Microsoft PowerPoint is not required.
