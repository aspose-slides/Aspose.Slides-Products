{{% blocks/products/pf/feature-page-section  h2="Convert POT to PPTX using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Pptx`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to PPTX" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```
