[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an FODP presentation and save it in the PowerPoint 97–2003 PPT format. {{% blocks/products/pf/feature-page-section  h2="Convert FODP to PPT using Python" %}}
Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Ppt` to create the PPT file.

{{% blocks/products/pf/agp/code-block title="Python code for converting FODP to PPT" offSpacer="true" %}}

```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
