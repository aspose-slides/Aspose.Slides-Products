{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to PPT using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Ppt` to create the PPT file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to PPT" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
