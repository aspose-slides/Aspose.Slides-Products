{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to HTML using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Html` to generate an HTML document.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to HTML" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.html", SaveFormat.Html)
finally:
    presentation.dispose()
```
