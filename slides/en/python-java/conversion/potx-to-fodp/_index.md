{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to FODP using Python" variant="code" %}}

Create a `Presentation` from the POTX file, then call `save` with `SaveFormat.Fodp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to FODP" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.fodp", SaveFormat.Fodp)
finally:
    presentation.dispose()
```
