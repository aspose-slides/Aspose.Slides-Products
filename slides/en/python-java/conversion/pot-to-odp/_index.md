{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POT to ODP using Python" variant="code" %}}

Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Odp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POT to ODP" >}}
```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
