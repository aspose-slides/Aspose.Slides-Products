{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTM to PPSX using Python" variant="code" %}}

Create a `Presentation` from the POTM file, then call `save` with `SaveFormat.Ppsx`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTM to PPSX" >}}
```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.ppsx", SaveFormat.Ppsx)
finally:
    presentation.dispose()
```
