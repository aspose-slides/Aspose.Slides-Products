{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert ODP to PPTM using Python" variant="code" %}}

Create a `Presentation` from the ODP file and call `save` with `SaveFormat.Pptm` to create the PPTM file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting ODP to PPTM" >}}
```python
presentation = Presentation("presentation.odp")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```

[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an ODP presentation and save it as a PPTM file. PPTM is the macro-enabled Office Open XML presentation format; converting an ODP file does not add VBA macros to it. The conversion does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.
