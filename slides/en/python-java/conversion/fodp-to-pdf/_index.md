{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to PDF using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Pdf` to generate the PDF document.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to PDF" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.pdf", SaveFormat.Pdf)
finally:
    presentation.dispose()
```
