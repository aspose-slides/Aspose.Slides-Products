{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert OTP to PPSM using Python" variant="code" %}}

Create a `Presentation` from the OTP file and call `save` with `SaveFormat.Ppsm` to create the PPSM slide show.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting OTP to PPSM" >}}
```python
presentation = Presentation("presentation.otp")
try:
    presentation.save("presentation.ppsm", SaveFormat.Ppsm)
finally:
    presentation.dispose()
```

[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an OTP presentation template and save it as a PPSM file. PPSM is the macro-enabled Office Open XML format for PowerPoint slide shows; converting an OTP file does not add VBA macros to it. The conversion does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.
