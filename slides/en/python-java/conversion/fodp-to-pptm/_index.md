{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert FODP to PPTM using Python" variant="code" %}}

Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Pptm` to create the PPTM file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting FODP to PPTM" >}}
```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
