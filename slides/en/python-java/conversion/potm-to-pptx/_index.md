{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTM to PPTX using Python" variant="code" %}}

Create a `Presentation` from the POTM file and call `save` with `SaveFormat.Pptx` to create the PPTX file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTM to PPTX" >}}
```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.pptx", SaveFormat.Pptx)
finally:
    presentation.dispose()
```
