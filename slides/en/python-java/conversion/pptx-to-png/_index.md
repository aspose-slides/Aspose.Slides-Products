{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to PNG using Python" variant="code" %}}

Create a `Presentation` from the PPTX file, access each slide through a variable, call `getImage`, and save the rendered image with `ImageFormat.Png`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX slides to PNG" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    slide_count = presentation.getSlides().size()

    for slide_index in range(slide_count):
        slide = presentation.getSlides().get_Item(slide_index)
        slide_image = slide.getImage(2, 2)
        try:
            file_path = f"slide-{slide_index + 1}.png"
            slide_image.save(file_path, ImageFormat.Png)
        finally:
            slide_image.dispose()
finally:
    presentation.dispose()
```
