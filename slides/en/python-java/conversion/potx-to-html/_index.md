{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to HTML using Python" variant="code" %}}

Create a `Presentation` from the POTX file and call `save` with `SaveFormat.Html` to generate an HTML document.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to HTML" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.html", SaveFormat.Html)
finally:
    presentation.dispose()
```
