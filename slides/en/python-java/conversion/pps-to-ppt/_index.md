{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPS to PPT using Python" variant="code" %}}

Create a `Presentation` from the PPS file, then call `save` with `SaveFormat.Ppt`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPS to PPT" >}}
```python
presentation = Presentation("presentation.pps")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
