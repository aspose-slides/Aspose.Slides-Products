{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSM to TIFF using Python" variant="code" %}}

Create a `Presentation` from the PPSM file and call `save` with `SaveFormat.Tiff` to create the TIFF image.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSM to TIFF" >}}
```python
presentation = Presentation("presentation.ppsm")
try:
    presentation.save("presentation.tiff", SaveFormat.Tiff)
finally:
    presentation.dispose()
```
