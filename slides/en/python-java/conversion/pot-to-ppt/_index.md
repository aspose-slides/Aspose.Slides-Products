{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POT to PPT using Python" variant="code" %}}

Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Ppt`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POT to PPT" >}}
```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
