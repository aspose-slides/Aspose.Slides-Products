[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a PowerPoint 97–2003 template (POT) and save it as a PowerPoint 97–2003 presentation (PPT). This changes the document type from a reusable template to an editable presentation while retaining the legacy binary file format. Microsoft PowerPoint is not required.

{{% /blocks/products/pf/feature-page-section %}}

{{% blocks/products/pf/feature-page-section  h2="Convert POT to PPT using Python" %}}
Create a `Presentation` from the POT file, then call `save` with `SaveFormat.Ppt`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POT to PPT" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pot")
try:
    presentation.save("presentation.ppt", SaveFormat.Ppt)
finally:
    presentation.dispose()
```
