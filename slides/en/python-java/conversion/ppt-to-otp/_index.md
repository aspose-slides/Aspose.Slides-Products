{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPT to OTP using Python" variant="code" %}}

Create a `Presentation` from the source PPT file, then call `save` with `SaveFormat.Otp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPT to OTP" >}}
```python
presentation = Presentation("presentation.ppt")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
