{{% blocks/products/pf/feature-page-section  h2="How to Convert PPS to PDF in Python" %}}
Load the source PPS file into a `Presentation`, then save it with `SaveFormat.Pdf`.

{{% blocks/products/pf/agp/code-block title="Python tutorial for converting PPS into PDF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pps")
try:
    presentation.save("presentation.pdf", SaveFormat.Pdf)
finally:
    presentation.dispose()
```
