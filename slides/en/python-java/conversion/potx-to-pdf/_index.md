{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to PDF using Python" variant="code" %}}

Create a `Presentation` from the POTX file, then call `save` with `SaveFormat.Pdf`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to PDF" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.pdf", SaveFormat.Pdf)
finally:
    presentation.dispose()
```
