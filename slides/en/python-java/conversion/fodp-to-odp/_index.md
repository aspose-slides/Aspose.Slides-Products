[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an FODP file, which stores an OpenDocument presentation as flat XML, and save it as a packaged ODP presentation. The conversion preserves the presentation structure and does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.

{{% blocks/products/pf/feature-page-section  h2="Convert FODP to ODP using Python" %}}
Create a `Presentation` from the FODP file and call `save` with `SaveFormat.Odp` to create the ODP presentation.

{{% blocks/products/pf/agp/code-block title="Python code for converting FODP to ODP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.fodp")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
