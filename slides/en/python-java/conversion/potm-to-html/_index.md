Create a `Presentation` from the POTM file and call `save` with `SaveFormat.Html` to generate an HTML document.

{{% blocks/products/pf/agp/code-block title="Python code for converting POTM to HTML" offSpacer="true" %}}

```python

try:
    presentation.save("presentation.html", SaveFormat.Html)
finally:
    presentation.dispose()
```
