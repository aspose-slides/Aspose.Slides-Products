{{% blocks/products/pf/feature-page-section  h2="Convert POTM to POTX using Python" %}}
Create a `Presentation` from the POTM file, then call `save` with `SaveFormat.Potx`.

{{% blocks/products/pf/agp/code-block title="Python code for converting POTM to POTX" offSpacer="true" %}}

```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.potx", SaveFormat.Potx)
finally:
    presentation.dispose()
```
