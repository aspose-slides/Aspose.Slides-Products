{{% blocks/products/pf/feature-page-section  h2="Convert PPSX to TIFF using Python" %}}
Create a `Presentation` from the PPSX file, then call `save` with `SaveFormat.Tiff`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPSX to TIFF" offSpacer="true" %}}

```python
presentation = Presentation("presentation.ppsx")
try:
    presentation.save("presentation.tiff", SaveFormat.Tiff)
finally:
    presentation.dispose()
```
