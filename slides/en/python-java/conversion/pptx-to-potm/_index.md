{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTX to POTM using Python" variant="code" %}}

Create a `Presentation` from the PPTX file and call `save` with `SaveFormat.Potm` to create the POTM file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTX to POTM" >}}
```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.potm", SaveFormat.Potm)
finally:
    presentation.dispose()
```
