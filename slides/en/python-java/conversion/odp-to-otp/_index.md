[**Aspose.Slides for Python via Java**](/slides/python-java/) can load an ODP presentation and save it as an OTP file. The OTP output is an OpenDocument presentation template that can be used as the basis for new presentations. The conversion does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.

{{% blocks/products/pf/feature-page-section  h2="Convert ODP to OTP using Python" %}}
Create a `Presentation` from the ODP file and call `save` with `SaveFormat.Otp` to create the OTP presentation template.

{{% blocks/products/pf/agp/code-block title="Python code for converting ODP to OTP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.odp")
try:
    presentation.save("presentation.otp", SaveFormat.Otp)
finally:
    presentation.dispose()
```
