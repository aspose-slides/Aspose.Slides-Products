{{% blocks/products/pf/feature-page-section  h2="Convert ODP to FODP using Python" %}}

{{% blocks/products/pf/agp/code-block title="Python code for converting ODP to FODP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.odp")
try:
    presentation.save("presentation.fodp", SaveFormat.Fodp)
finally:
    presentation.dispose()
```
