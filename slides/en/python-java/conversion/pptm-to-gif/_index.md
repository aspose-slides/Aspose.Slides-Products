{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to GIF using Python" variant="code" %}}

Create a `Presentation` from the source PPTM file, then call `save` with `SaveFormat.Gif` to generate an animated GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to animated GIF" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
