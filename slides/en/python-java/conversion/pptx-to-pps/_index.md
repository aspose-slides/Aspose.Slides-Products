{{% blocks/products/pf/feature-page-section  h2="Convert PPTX to PPS using Python" %}}
Create a `Presentation` from the PPTX file and call `save` with `SaveFormat.Pps` to create the PPS slide show.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTX to PPS" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptx")
try:
    presentation.save("presentation.pps", SaveFormat.Pps)
finally:
    presentation.dispose()
```
