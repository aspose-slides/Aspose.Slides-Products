[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a macro-enabled PowerPoint presentation (`.pptm`) and save it in OpenDocument Presentation (`.odp`) format. {{% blocks/products/pf/feature-page-section  h2="Convert PPTM to ODP using Python" %}}
Create a `Presentation` from the source PPTM file, then call `save` with `SaveFormat.Odp`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTM to ODP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
