{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPTM to ODP using Python" variant="code" %}}

Create a `Presentation` from the source PPTM file, then call `save` with `SaveFormat.Odp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPTM to ODP" >}}
```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
