{{% blocks/products/pf/feature-page-section  h2="Convert PPTM to PPS using Python" %}}
Create a `Presentation` from the PPTM file, then call `save` with `SaveFormat.Pps`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPTM to PPS" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pptm")
try:
    presentation.save("presentation.pps", SaveFormat.Pps)
finally:
    presentation.dispose()
```
