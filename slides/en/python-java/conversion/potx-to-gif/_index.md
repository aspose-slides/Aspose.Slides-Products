{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTX to GIF using Python" variant="code" %}}

Create a `Presentation` from the POTX file and call `save` with `SaveFormat.Gif` to create an animated GIF.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTX to animated GIF" >}}
```python
presentation = Presentation("presentation.potx")
try:
    presentation.save("presentation.gif", SaveFormat.Gif)
finally:
    presentation.dispose()
```
