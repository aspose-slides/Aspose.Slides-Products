{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPT to ODP using Python" variant="code" %}}

Create a `Presentation` from the source PPT file, then call `save` with `SaveFormat.Odp`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPT to ODP" >}}
```python
presentation = Presentation("presentation.ppt")
try:
    presentation.save("presentation.odp", SaveFormat.Odp)
finally:
    presentation.dispose()
```
