[**Aspose.Slides for Python via Java**](/slides/python-java/) can load a PowerPoint 97–2003 slide show (`PPS`) and export it as a Flat OpenDocument Presentation (`FODP`). The conversion stores the presentation in a flat XML-based format and does not require Microsoft PowerPoint, LibreOffice, or OpenOffice.

{{% /blocks/products/pf/feature-page-section %}}

{{% blocks/products/pf/feature-page-section  h2="Convert PPS to FODP using Python" %}}
Create a `Presentation` from the PPS file, then call `save` with `SaveFormat.Fodp`.

{{% blocks/products/pf/agp/code-block title="Python code for converting PPS to FODP" offSpacer="true" %}}

```python
presentation = Presentation("presentation.pps")
try:
    presentation.save("presentation.fodp", SaveFormat.Fodp)
finally:
    presentation.dispose()
```
