{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert POTM to POT using Python" variant="code" %}}

Create a `Presentation` from the POTM file, then call `save` with `SaveFormat.Pot`.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting POTM to POT" >}}
```python
presentation = Presentation("presentation.potm")
try:
    presentation.save("presentation.pot", SaveFormat.Pot)
finally:
    presentation.dispose()
```
