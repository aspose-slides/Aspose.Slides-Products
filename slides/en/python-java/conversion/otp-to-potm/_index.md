{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert OTP to POTM using Python" variant="code" %}}

Create a `Presentation` from the OTP file and call `save` with `SaveFormat.Potm` to create the POTM file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting OTP to POTM" >}}
```python
presentation = Presentation("presentation.otp")
try:
    presentation.save("presentation.potm", SaveFormat.Potm)
finally:
    presentation.dispose()
```
