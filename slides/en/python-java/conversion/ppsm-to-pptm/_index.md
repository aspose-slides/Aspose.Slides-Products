{{% blocks/products/pf/slides-design-update-10-2026/section h2="Convert PPSM to PPTM using Python" variant="code" %}}

Create a `Presentation` from the PPSM file and call `save` with `SaveFormat.Pptm` to create the PPTM file.

{{< blocks/products/pf/slides-design-update-10-2026/code title="Python code for converting PPSM to PPTM" >}}
```python
presentation = Presentation("presentation.ppsm")
try:
    presentation.save("presentation.pptm", SaveFormat.Pptm)
finally:
    presentation.dispose()
```
